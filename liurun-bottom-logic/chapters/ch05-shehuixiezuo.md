# 第 5 章：社会协作的底层逻辑

## Core Idea

社会协作的底层是四件事：选对法则（自然/族群/普遍）、积累势能（技术/模式）、把分配关系设计对（优先劣后、稀缺、信用），并在效率与公平之间找平衡。

## Frameworks Introduced

- **世界三大法则**：自然法则（物竞天择，保护自己）、族群法则（出让部分权利换群体目标，组织内遵守规矩）、普遍法则（跨越组织的共同价值，如尊重生命、契约精神）。
- **战略势能**：战争的本质是对能量的控制；商业模式创造势能、科技也是势能；**求之于势，不责于人**。
- **定价 = 消费者感知价值**：功能价值 < 体验价值 < 个性化价值；越稀缺越贵；性价比竞争是价格战，差异化才有定价权。
- **利润三分法**：趋势红利（运气）、社会工资（竞争拉平后的辛苦费）、创新利润（只有你做得更好且别人学不会）。**利润，来自没有竞争。**
- **儒家式管理（无 KPI）**：只招成年人、付最高固定工资、取消考核与考勤、用晋升选拔人才；与认知相关的工作不用 KPI 激励（KPI 会诱导取悦上级、压抑创造力）。
- **三种共同体**：利益共同体（短期利益）、事业共同体（长期共同利益、风险共担）、命运共同体（共同不能失去的东西）。
  - 判断：降薪 50% 换 500% 收益 → 事业共同体；再投 500 万换 5000% → 命运共同体。
- **财富公式与分配权**：财富 = 劳动 × 生产率 × 效用；创造财富靠能力，**分配财富靠稀缺**——谁掌握稀缺资源，谁拥有财富分配权。
- **优先劣后 / 固定、剩余、分成**：员工拿优先（固定），老板拿劣后（剩余）；激励员工用分成；合作中竞争优势小者拿固定、大者拿剩余；交易成本高时小者拿高固定 + 低分成。
- **信用是一个人最大的资产**：被信任降低交易成本；信用中介是交易结构里的「结构洞」（黑市中间人抽走 95%）；信用靠一生沉淀、一分钟毁掉。
- **公平、公正、公开**：公平 = 同一把尺子；公正 = 选哪把尺子（谁有权定义谁担责）；公开 = 过程展示给公众监督。
- **效率与公平**：初次分配负责效率（资源给用得最好的人），再分配负责公平；公平是下一个时代的红利。
- **服从性测试**：劝酒、拎包、无理取闹都是测试「理解要执行，不理解也要执行」的服从度。

## Key Concepts

- **自然 / 族群 / 普遍法则**：世界协作的三层规则。
- **势能**：水攻、商业模式、科技都是积蓄的势能。
- **功能 / 体验 / 个性化价值**：定价的三种依据。
- **趋势红利 / 社会工资 / 创新利润**：你赚的钱到底是哪种。
- **结构洞**：占据交易环节关键位置、掌握最多信息的人（信用中介）。
- **优先利 / 劣后利**：固定优先回报 vs 剩余回报。
- **科斯定理**：资源总会落到用得最好的人手里（交易成本为零时）。

## Mental Models

- 用更高法则与世界协作，用自然法则保护自己。
- 先建坝蓄能再推石：战略上求势，不责于人。
- 别把趋势红利当能力，别把社会工资当利润。
- 让自己和公司不断变稀缺：稀缺 = 分配权。
- 激励的本质是激发善意，不是用 KPI 交换行为。

## Anti-patterns

- **用错法则**：跟巨婴讲道理、跟野蛮人签协议。
- **用个位努力对抗千位变化**：管理救不了错误的行业。
- **以为赚的都是利润**：红利会被拿走，社会工资是辛苦费。
- **用 KPI 管理创造性工作**：压抑创造力、诱导取悦上级、破坏协作。
- **假装事业共同体**：招为钱工作的员工却谈梦想，是最尴尬的位置。
- **劝酒 / 服从性测试被滥用**：看清它是测试，选择回应方式。

## Worked Example

效率与公平：老王（手艺 8）vs 小张（手艺 2），宝玉（品质 9）vs 碎石（品质 3）。
- 宝玉给老王：9×8 + 3×2 = 78 总收入，但小张只拿 6，「不公平」。
- 宝玉给小张：3×8 + 9×2 = 42 总收入，收入差距缩小，但社会总财富从 78 跌到 42，「低效率」。
- 结论：初次分配支持老王（效率），再分配（税收、救济、培训）支持小张（公平）。改革开放「让一部分人先富起来」就是效率优先，再通过再分配回馈。

## Key Takeaways

1. 自然法则保护自己，族群法则守规矩，普遍法则找共同点；法则越高级换得越多，也越脆弱。
2. 商业模式和科技都是势能：求之于势，不责于人。
3. 定价权来自消费者感知价值：功能 < 体验 < 个性化。
4. 利润来自没有竞争：趋势红利是运气，社会工资是辛苦费，创新利润才是真利润。
5. 与认知相关的工作别用 KPI；付高固定工资、激发善意、用晋升选拔。
6. 分钱 = 优先劣后的组合：员工优先固定，老板劣后剩余，激励用分成。
7. 信用是最大资产；公平、公正、公开三件事分开谈；公平是下一个时代的红利。
