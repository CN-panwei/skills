# 第 1 章：是非对错的底层逻辑

## Core Idea

判断对错不是看道理，而是看损失落在谁身上、由谁承担责任。底层逻辑是「不同之中的相同、变化背后不变的东西」，只有它能跨环境生成新方法论。

## Frameworks Introduced

- **三种对错观**：面对同一件事，法学家按法律归责、经济学家按社会总成本归责、商人按个体利益最大化归责。
  - When to use：评论他人选法学家视角，制定政策选经济学家视角，自己身处其中选商人视角。
  - How：问「谁的损失最大」→ 损失最大者负责 → 由他改变结果。
- **课题分离（阿德勒）**：区分「谁的课题」。绑架索要赎金是绑匪的课题，因绑架受损失是首富的课题。
- **人性、道德、法律**：人性 = 生存繁衍；道德 = 约束人性的社会契约（常反人性）；法律 = 道德的子集（底线）。
  - When to use：区分「没人性 / 不道德 / 犯法」三种评价，避免混用。
- **人生的三层智慧**：选择（放弃）为第一层，定力（长期主义）为第二层，博弈（共赢感激 + 一报还一报）为第三层。
- **公理体系 vs 逻辑推演**：经济学没有公理，所以没有唯一正确答案。
  - 学习三原则：学李白也要学杜甫（兼听）；给每个模型找个反例（查理·芒格：反驳不了就不配拥有）；记住每个理论都有前提（如「价格决定成本」的前提是其他要素不变）。

## Key Concepts

- **底层逻辑**：不同之中的相同、变化背后的不变（序言）。
- **课题分离**：谁的课题谁负责，解决人际烦恼的关键。
- **社会契约**：道德的本质，为群体繁荣而约束个体。
- **一报还一报**：博弈策略，重复对方上次动作，最好生存策略。
- **长期主义**：定力的同义词；贝佐斯 1997 年股东信「一切都围绕长期价值」。
- **逻辑自洽**：信仰的特征——信仰内自洽、信仰间矛盾。
- **公理**：不需证明的选择与共识，是推演体系的根基。

## Mental Models

- 谁的损失大，就是谁的错（归因时先看损失，再看道理）。
- 道德常常是反人性的，所以需要引导（宣传）和约束（惩罚）。
- 选择 > 定力 > 博弈：先选对事，再用长期主义坚持，最后在博弈中守底线。
- 把公司的愿景使命价值观当作公理：制度与公理冲突时改制度，不动公理。

## Anti-patterns

- **责怪、埋怨、后悔**：改变不了结果，只会浪费精力。
- **只学「更对」的一门经济学**：经济学无公理体系，必须兼听并给每个模型找反例。
- **丢掉理论前提只记结论**：「价格决定成本」「科斯定律」都被人为划掉了「其他要素不变 / 交易成本为零」的前提。
- **和有立场的人争对错**：立场由位置和利益决定，争不赢也伤关系。

## Worked Example

坏人 A 诱骗好人 B 进入 C 的没锁门工地，B 失足摔死，谁的错？
- 法学家：A 的错（蓄意谋杀）。
- 经济学家：C 的错——全社会避免此类事故的成本，远高于 C 锁门，惩罚 C 让所有工地锁门，事故大量减少。
- 商人：B 只能怪自己——无论谁担责，B 都无法复生；从个体利益最大化，B 应怪自己「不该蠢到被骗」。

应用：如果当事人是你，就选商人视角，因为只有自己的行动能改变自己的结果。

## Key Takeaways

1. 判断对错先问「谁的损失大」，损失大者负责，靠自己改变结果。
2. 人性来自基因，道德是反人性的社会契约，法律是道德的底线，三者评价体系不同。
3. 人生的三层智慧按「选择、定力、博弈」排序：选择即放弃，定力即长期主义，博弈守共赢。
4. 学任何非公理学科，都要兼听不同学派、主动找反例、牢记理论前提。
5. 底层逻辑 + 环境变量 = 方法论：学规律，不学死方法。
