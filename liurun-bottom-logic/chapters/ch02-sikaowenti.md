# 第 2 章：思考问题的底层逻辑

## Core Idea

思考问题的差距，不是努力程度的差距，而是「看表象还是看系统」的差距：普通的人改变结果，优秀的人改变原因，顶级优秀的人改变模型。

## Frameworks Introduced

- **事实、观点、立场、信仰**：事实有真假，观点无对错，立场是利益影响下的观点，信仰是自洽逻辑体系。
- **注射式洗脑**：句式「为什么 + 观点」会把观点悄悄注射进大脑。
  - When to use：听到「为什么 X」先质疑 X 是否为真，再决定是否回答。
- **辩论三要素**：目的是说服观众而非对方；关键是重新定义概念；核心竞争力是基于逻辑的急智。
- **假设—验证—结论—调整**：遇到问题不凭经验，大胆假设、小心求证、就事论事。
- **洞察力模型（系统五模块）**：变量（存量/流量）、因果链（+/-）、增强回路、调节回路、滞后效应。
  - How：找核心存量 → 关键因果链 → 增强回路 → 调节回路 → 滞后效应。
- **流程、制度、系统**：制度关注结果（改结果），流程关注过程（改原因），系统关注关系（改模型）。
- **逻辑素养四句话**：证有不证无，以偏不概全，证有靠举例，概全靠推理。
- **逻辑闭环五层次**：从无闭环到有闭环，最高层次是有闭环、有逻辑、永远开放、不断打碎自己。
- **复利思维**：本金 ×（1+收益率）^时间 − 欲望 = 财富自由；三大谬误：期数谬误、复利效果谬误、收益率谬误。
- **概率思维**：运气 = 概率；成功由时代（千位）> 战略（百位）> 治理（十位）> 管理（个位）决定；对冲概率而非否认概率。
- **五种数学思维**：从不确定性中找到确定性（正确的事重复做）、微积分（动态眼光）、公理体系、数字的方向性（向量）、全局最优与共赢。
- **系统思维**：商业模式 = 利益相关者的交易结构；所有战略都是站在未来看今天。

## Key Concepts

- **存量与流量**：浴缸里的水（存量）vs 流入流出（流量）；不满的情绪是存量，小事是流入量。
- **增强回路 / 调节回路**：让世界走向极端 vs 回归平衡；凡有增强回路处必有调节回路。
- **滞后效应**：因果间的时间差，给万事万物加上时间轴。
- **幸存者偏见**：只看到飞回来的飞机，看不到被击落的。
- **期望值**：50% × 1 亿 + 50% × 0 = 5000 万，理性决策看期望值。
- **边际交付时间**：见 Ch3，但第 2 章「商业模式」已埋下交易结构视角。
- **注射器**：「为什么 + 观点」的操纵工具。

## Mental Models

- 给万事万物加时间轴（滞后效应、微积分思维）。
- 用因果链连起所有变量，找出黑盒子里的连接关系。
- 正确的事情重复做：20% 概率的事重复 14 次，成功概率达 95%。
- 站在未来看今天；用「千百十个」定位问题所在层级。

## Anti-patterns

- **凭经验、想当然**：机翼弹孔的例子——看得见的经验常常是幸存者偏见。
- **被利益和立场左右**：开扯皮会时先归因到事，再谈人。
- **被「为什么 + 观点」注射**：问「我的产品最好为什么没人买」前，先质疑「产品最好」。
- **把复利当暴富**：期数、复利效果、收益率都被严重高估。
- **用个位努力对抗千位变化**：管理救不了错误的赛道。

## Worked Example

微软食堂午餐质量差的解决方案：
- 表象：供应商偷工减料。常规手段：派人盯、换菜谱、换大厨——都无效（供应商逐利，改进要成本）。
- 洞察：问题不在供应商，而在「微软与供应商的关系」——一家供应商没有危机感。
- 解法：引入第二家供应商，分别做午餐和晚餐，每三个月按满意度调查对调；连续半年午餐胜出就更换晚餐供应商。
- 本质：用竞争代替人工督促，改变连接关系（系统），而非改变要素。

## Key Takeaways

1. 区分事实、观点、立场、信仰，不跟立场争对错、不攻击信仰。
2. 先质疑「为什么」后面的观点，再回答「为什么」。
3. 洞察就是看清系统：变量、因果链、增强回路、调节回路、滞后效应五块积木。
4. 改变结果 < 改变原因 < 改变模型；治理优于管理。
5. 承认概率，再用时代、战略、治理、管理对冲概率；正确的事重复做。
6. 复利不是暴富，财富自由 = 本金×（1+收益率）^时间 − 欲望。
