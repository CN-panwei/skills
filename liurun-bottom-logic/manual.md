# 底层逻辑：看清这个世界的底牌 — 使用手册

> 使用方法：把你的问题直接讲出来，技能会自动激活。也可以带**主题词**（如「定价」「人脉」「KPI」「分钱」）或**章节号**（`ch01`–`ch05`）来精准调用某一章。

**作者**：刘润 ｜ **出版**：机械工业出版社 2021 ｜ **章节**：5 章

---

## 这个技能在做什么

它把《底层逻辑》全书拆成 5 个章节文件 + 3 个速查文件，让你在遇到真实问题时能直接调用刘润的框架，而不是凭印象复述。

核心用法是**按问题定位章节**：你描述一件事，它先判断这件事落在哪一章的射程内，读取该章后回答；问题跨章时会把相关章节的框架并起来用。超出书本范围的问题，它会明说而不是硬套。

全书的主线是一句话：**底层逻辑 + 环境变量 = 方法论**。底层逻辑是「不同之中的相同、变化背后不变的东西」——所以它给你的是规律，不是死方法。

## 五个功能模块（对应五章）

### 模块一：是非对错的底层逻辑 ——「谁的损失大，就是谁的错」（ch01）

**回答什么问题**：出了坏事该怪谁；怎么区分「没人性 / 不道德 / 犯法」；为什么跟有些人争论永远没有结果。

**核心工具**：
- **三种对错观** —— 同一件事，法学家按法律归责（坏人的错）、经济学家按社会总成本归责（能让事故减少最多的人担责）、商人按个体利益最大化归责（受害者只能怪自己）。**评论别人用法律视角，制定政策用经济视角，轮到自己时用商人视角。**
- **人性、道德、法律** —— 人性 = 生存繁衍（无善无恶）；道德 = 约束人性以促成群体繁荣的社会契约，所以**常常反人性**；法律 = 道德的子集（底线）。引导靠文化宣传，约束靠惩罚制度。
- **人生的三层智慧** —— 选择（选择就是放弃）> 定力（长期主义）> 博弈（共赢感激 + 一报还一报）。
- **公理体系思维** —— 公司的愿景使命价值观是「公理」，制度流程是推出来的「定理」。**制度与公理冲突时，改制度，不动公理。**
- **阿德勒课题分离** —— 分清「谁的课题」，解决人际烦恼的关键。

**你获得什么**：一套归因方法——先问「谁的损失大」，再看道理。以及一个判断习惯：这句话是事实、观点、立场还是信仰（立场不争、信仰不碰）。

**典型例子**：坏人 A 诱骗好人 B 进入 C 没锁门的工地，B 摔死，谁的错？法学家说 A，经济学家说 C（惩罚 C 能让所有工地锁门），商人说 B 只能怪自己（无论谁担责 B 都无法复生）——如果你就是当事人，选商人视角，因为只有你的行动能改变你的结果。

### 模块二：思考问题的底层逻辑 ——「普通人改变结果，优秀的人改变模型」（ch02）

**回答什么问题**：为什么同一件事有人只看到表象、有人看到系统；为什么会被人「带节奏」；复利到底靠不靠谱；怎么评估一件有风险的事。

**核心工具**：
- **洞察力模型（系统五模块）** —— 变量（存量/流量）、因果链、**增强回路**、**调节回路**、**滞后效应**。诊断五步：找核心存量 → 找关键因果链 → 找增强回路 → 找调节回路 → 考虑滞后效应。
- **改变的三层** —— 改制度是改结果，改流程是改原因，**改系统（重排连接关系）才是治理**。
- **事实 / 观点 / 立场 / 信仰** —— 判断该跟什么争论、该绕开什么。
- **注射式洗脑** —— 「为什么 + 观点」这个句式会把观点偷偷注射进你的大脑。听到「为什么 X」，先问「X 是真的吗」。
- **概率思维（千百十个）** —— 成功由时代（千位）> 战略（百位）> 治理（十位）> 管理（个位）决定。用个位的努力对抗千位的变化，如同螳臂当车。**正确的事重复做**：20% 概率的事做 14 次，成功率到 95%。
- **复利思维** —— 本金 ×(1+收益率)^时间 − 欲望 = 财富自由；拆穿三大谬误（期数高估、复利效果高估、收益率高估）。

**你获得什么**：从「头痛医头」升级到「看到结构」。以及一句能挡住大半忽悠的话：**先质疑「为什么」后面那个前提**。

**典型例子**：微软食堂午餐难吃。派人盯、换菜谱、换大厨都无效——问题不在供应商，而在「微软与供应商的关系」（只有一家，没有危机感）。解法是引入第二家，分别做午餐和晚餐，每三个月按满意度对调。**用竞争代替督促，是改连接关系，不是改要素。**

### 模块三：个体进化的底层逻辑 ——「人生是一种商业模式」（ch03）

**回答什么问题**：怎么用 2 年获得别人 5 年的能力；该做产品还是做服务；怎么经营人脉；时间该怎么管。

**核心工具**：
- **人生商业模式 = 能力 × 效率 × 杠杆**
  - **能力**：最可怕的能力是「获得能力的能力」——勤奋 → 可怕的勤奋 → **高效而可怕的勤奋**（刻意练习，关键是反馈机制）。
  - **效率**：**选择 > 方法 > 工具**。用 17 分钟判断值不值得做 17 小时的事，而不是从 17 分钟里省出 17 秒。
  - **杠杆**：团队、产品、资本、影响力四种。**前提是先有强大的能力内核**——杠杆只做复制放大，内核虚弱时杠杆加速失败。
- **边际交付时间** —— 边际交付时间为零 = **产品**（幂律分布、赢家通吃、可指数增长）；不为零 = **服务**（正态分布、分散、稳）。想指数增长，就把边际交付时间为零的部分剥离出来自己做（麦当劳做标准与品牌、樊登只做「每年读 50 本书」）。
- **时间颗粒度** —— 安排时间的基本单位（王健林 15 分钟、盖茨 5 分钟）；**恪守时间 = 理解并尊重别人的时间颗粒度**。
- **人脉 10-30-60** —— 能借钱的不过 10 人、常交往不过 30 人、熟人不过 60 人。**你能帮到的人，才是你的人脉。**
- **知识 / 技能 / 态度** —— 知识用脑记（已证明的规律）、技能用手练（练成条件反射）、态度用心选（没人能教）。别把知识当技能学，也别把技能当知识学。
- **自污、示弱、看淡** —— 用自污邀请善意而非恶意，示弱邀请帮助，用内心价值观评价自己以看淡误解。**心态高过云端，姿态埋入地底。**

**你获得什么**：一个可算的自我经营模型。以及一个选赛道的硬标准：**这件事有没有边际交付时间为零的部分**。

**典型例子**：一个既会画画又会弹钢琴的高中毕业生。画画每幅 3 小时，边际交付时间高 → 正态分布，难大富但不会没饭吃；钢琴演奏一次可复制成唱片，边际交付时间为零 → 幂律分布，可能极大成功也可能碌碌无为。选哪个都行，但要清楚自己在哪种竞争格局里。

### 模块四：理解他人的底层逻辑 ——「沟通是匹配，不是说服」（ch04）

**回答什么问题**：为什么讲了半天对方不买账；怎么把复杂的事讲明白；什么是边界感；怎么激励人。

**核心工具**：
- **黄金三问（What / Why / How）** —— 真正的「知道」必须同时掌握三问；**没有 Why 就没有动力，没有 How 就只是鸡汤**。沟通前先判断对方要听的是哪一问——问 What 答 Why，必然鸡同鸭讲。
- **幽默的三种机制** —— 优越感（制造失败者）、错愕感（逻辑线急转弯）、释放感（危险 + 安全）。前提是**幽默是溢出的智慧**，只有举重若轻的人才有余力幽默。
- **打比方三步** —— 洞察复杂陌生事物的本质 → 匹配到大家熟悉的事物 → 用熟悉的解释陌生的。会打比方 = 同时理解两种事物的本质。
- **边界感 = 对所有权的认知** —— 时间、隐私、权利的所有权都清楚是谁的，越界先征求同意。讨论时充分表达，决定后坚决执行——**表达的权利是你的，接受的权利是对方的。**
- **多巴胺 / 内啡肽 / 血清素与奖励机制表** —— 多巴胺管**动机**（支持攀登、享受过程），**与快乐无关**；内啡肽（运动）和血清素才是快乐来源。商业就是研究并运用这张表：用比较优势（排行榜）、安全感、炫耀（品牌标识）刺激快乐因子分泌。

**你获得什么**：一套「先判断对方要什么，再决定说什么」的沟通习惯。以及一个识别自身状态的坐标：你现在是被多巴胺驱动（动机），还是在体验快乐。

**典型例子**：有人问「怎么一个月赚 1000 万」。正面回答是「痴心妄想」；幽默回答是「很简单，闭着眼睛随机买 100 只股票，你的 1 亿资产就可以变成 1000 万了」——两条逻辑线（从 0 到 1000 万 / 从 1 亿到 1000 万）突然交叉，制造错愕。

### 模块五：社会协作的底层逻辑 ——「利润，来自没有竞争」（ch05）

**回答什么问题**：怎么跟不同类型的人打交道；我的利润是真的还是辛苦费；钱该怎么分；怎么设计激励；信用值多少。

**核心工具**：
- **世界三大法则** —— **自然法则**（物竞天择，用来保护自己）、**族群法则**（出让部分权利换群体目标，组织内守规矩）、**普遍法则**（跨组织的共同价值，如尊重生命、契约精神）。**法则越高级，能换到的东西越多，但人也越脆弱。**
- **战略势能** —— 战争的本质是对能量的控制；商业模式是势能、科技也是势能。**求之于势，不责于人**——先建坝蓄能，再轻轻一推。
- **定价 = 消费者能感知的价值** —— 功能价值 < 体验价值 < 个性化价值，越稀缺越贵。价格战没有出路，涨价（高端心智 + 毛利反哺）反而是对付价格战的方法。
- **利润三分法** —— **趋势红利**（运气，会被拿走）、**社会工资**（竞争拉平后的辛苦费）、**创新利润**（只有你做得比别人好且别人学不会，才是真利润）。
- **财富分配权** —— 财富 = 劳动 × 生产率 × 效用。**创造财富靠能力，分配财富靠稀缺**——谁掌握稀缺资源，谁拥有分配权。
- **优先劣后 / 固定、剩余、分成** —— 一切分钱无外乎优先与劣后；员工拿优先（固定），老板拿劣后（剩余），激励员工用分成。
- **儒家式管理（没有 KPI 也能管好公司）** —— 只招成年人、付最高固定工资、取消考核与考勤、用晋升选拔、激发善意。**与认知相关的工作不要用 KPI 激励**（会诱导取悦上级、压抑创造力）。
- **三种共同体** —— 涨薪 50% 愿意做 = 利益共同体；**降薪 50% 换 500% 收益**愿意 = 事业共同体；降薪 50% 再投 500 万换 5000% = 命运共同体。
- **信用是最大的资产** —— 信用降低交易成本，信用中介是交易结构里的「结构洞」。信用靠一生沉淀，一分钟就能毁掉。
- **公平、公正、公开** —— 公平 = 用同一把尺子丈量；公正 = 选哪把尺子（谁有权定义，谁承担责任）；公开 = 把丈量过程展示给公众监督。
- **效率与公平** —— 初次分配负责效率，再分配负责公平；公平是下一个时代的红利。
- **服从性测试** —— 劝酒、拎包、「无理取闹」的本质都是测试你是否「理解要执行，不理解也要执行」。看清它，你就知道如何选择回应。

**你获得什么**：三个能立刻自查的问题——**我用对法则了吗？我赚的是利润还是社会工资？我的分配结构是优先劣后还是拍脑袋？**

**典型例子**：老王手艺 8、小张手艺 2。宝玉（品质 9）给老王，总收入 9×8+3×2 = 78，但小张只拿 6，显得不公平；宝玉给小张，总收入 3×8+9×2 = 42，差距缩小但社会总财富从 78 跌到 42。结论：**初次分配支持老王（效率），再分配（税收、救济、培训）支持小张（公平）。**

## 适用场景

### 场景 1：出了事要定责 ——「这到底是谁的错」

**典型说法：** 项目搞砸了，是执行的人不行还是我带错了方向？合伙人撂挑子，我该怪他还是怪自己？

**它会给什么：** 三种对错观。关键是先分清你在哪个位置说话——评论别人用法律视角、制定规则用经济视角、**如果当事人是你，用商人视角（谁的损失大就是谁的错，因为只有你能改变结果）**。

### 场景 2：问题反复出现、治标不治本 ——「为什么总是这样」

**典型说法：** 同样的问题第三次发生了；考核改了三次还是不行；团队总是在同一个地方摔跤。

**它会给什么：** 系统五模块（变量→因果链→增强回路→调节回路→滞后效应）+ 改变三层（改结果 < 改原因 < 改模型）。它会带着你判断：这个问题的核心存量是什么、哪条回路在推它、你的干预点应该落在哪一层。

### 场景 3：被人带节奏或说服不了人 ——「为什么他听不进去」

**典型说法：** 我明明说得有道理，对方就是不接受；开会总在扯皮；有人老问我「为什么你产品这么好却卖不动」。

**它会给什么：** 事实/观点/立场/信仰四层分类 + 注射式洗脑识别 + 黄金三问。**先分清对方要听的是什么，再决定说什么；先质疑「为什么」后面那个前提，再决定要不要回答。**

### 场景 4：个人成长与时间投资 ——「怎么才能更快变强」

**典型说法：** 工作五年了感觉没长进；想学的东西太多不知道先学哪个；时间总是不够用。

**它会给什么：** 人生商业模式（能力×效率×杠杆）+ 刻意练习的反馈机制 + 效率排序（选择>方法>工具）+ 时间颗粒度。它会先问你：你的**能力内核**是什么？没有内核，谈杠杆和效率都是空的。

### 场景 5：职业/赛道选择 ——「做产品还是做服务」

**典型说法：** 我该做咨询还是做课程？我该继续接单还是做标准化产品？怎么才能不靠出卖时间赚钱？

**它会给什么：** 边际交付时间 + 正态分布 vs 幂律分布。判断标准很硬：**这件事有没有边际交付时间为零的部分**；有，就能指数增长，就该把那部分剥离出来自己做。

### 场景 6：收益与定价 ——「我赚的到底是什么钱」

**典型说法：** 这个行业人人都在赚钱但利润越来越薄；我要不要降价抢市场；为什么我这么辛苦还是不赚钱。

**它会给什么：** 利润三分法（趋势红利/社会工资/创新利润）+ 定价三层次（功能<体验<个性化）+ 稀缺决定分配权。它能帮你判断：你现在的收益里，哪些是运气、哪些是辛苦费、哪些才是真利润。

### 场景 7：分钱与激励 ——「怎么设计分配」

**典型说法：** 该给员工发多少固定工资和奖金？要不要给股权？为什么加了 KPI 反而更差了？

**它会给什么：** 优先劣后 + 固定/剩余/分成 + 四种支付（工资付责任、奖金付超额业绩、股权付未来潜力、价值观=命运共同体）+ 认知型工作不用 KPI。它会先问一句：你的团队是利益共同体、事业共同体还是命运共同体？**招来为钱工作的员工却谈梦想，是最尴尬的位置。**

### 场景 8：与人协作和博弈 ——「怎么跟不同类型的人打交道」

**典型说法：** 对方明显不讲理怎么办；合伙怎么谈规则；为什么劝酒这件事让我这么难受。

**它会给什么：** 世界三大法则（遇野蛮人用自然法则保护自己、组织内用族群法则守规矩、组织间用普遍法则找共同点）+ 边界感 + 服从性测试的识别。**法则越高级能换到的东西越多，但人也越脆弱**——这是选择的代价，不是道德高低。

## 深度追问：答案太浅时怎么逼它

**觉得它在背概念、没落到你的事上：**
```
别讲框架本身，直接用这个框架分析我这件事，给出我明天能做的第一步。
```

**觉得它给的是常识：**
```
这跟「多沟通、多换位思考」这种常识有什么区别？说清这个框架能让我看到什么别人看不到的。
```

**想知道反例和边界：**
```
这个框架在什么情况下会失效？给我一个它不适用的反例。
```

**想确认不是编的：**
```
这句话出自哪一章？把该章相关段落原文给我看。
```

**觉得它只会顺着你说：**
```
按「商人视角」和「经济学家视角」分别给我一个跟现在相反的结论。
```

**想直接跳到行动：**
```
跳过分析，直接告诉我：按这本书的框架，我现在最该改的是哪一件事？为什么是它而不是别的？
```

## 支持文件（什么时候用哪个）

技能目录里有三份辅助文件，会根据你的问题自动调用，你也可以点名要：

| 文件 | 内容 | 什么时候用 |
|---|---|---|
| `chapters/ch01–ch05.md` | 五章完整框架、概念、心智模型、反模式、案例、要点 | 需要深入某一章时 |
| `glossary.md` | 全书关键术语定义（按拼音排序，标注出处章节） | 看到不熟的术语时 |
| `patterns.md` | 可复用的方法与模式（含 When to use / How / Trade-offs） | 想直接拿做法时 |
| `cheatsheet.md` | 决策规则速查表，含「识别信号（Tells & Smells）」 | 想快速查规则或识别套路时 |

其中 **`cheatsheet.md` 的「识别信号」一节最值得单独一看**——它把书里的判断力压缩成了几条可即时触发的警报，例如：

- 听到「为什么 + 观点」→ 有人在给你注射观点
- 对方频繁迟到/临时改约 → 时间颗粒度太粗，或不够职业化
- 行业人人能赚、利润越来越薄 → 赚的是趋势红利，正在被拉平成社会工资
- 某公司天天喊忠诚度、企业文化留人 → 大概率处于「转型困境」，留不住优秀员工
- 有人劝酒、让你拎包、「无理取闹」→ 服从性测试，先看清再回应
- 「每天进步 1%」「7 年翻倍」→ 复利谬误套餐，逐一拆穿

## 它的边界（必读）

**一、只覆盖这一本书。** 本技能只基于《底层逻辑》（刘润，2021）建构。它不会引用刘润的其他著作（《5 分钟商学院》《商业洞察力》等），也不会引用其他作者的观点——**如果它给出了书外的内容，请质问它出处**。

**二、框架不是建议。** 书里的框架是**思维工具**，不是投资、管理或法律建议。用于真实业务决策时，请结合你自己的具体情境与数据。

**三、它有明确的立场。** 这本书的立场偏「商人视角」和「效率优先」——比如「谁的损失大就是谁的错」「利润来自没有竞争」「认知型工作不要用 KPI」。这些是刘润的选择而非普遍真理，用的时候要清楚自己在采纳谁的世界观。想要对冲，可以同时用其他视角（比如经济学视角看公平、组织行为学视角看激励）来看同一件事。

**四、它不能替你承担判断。** 技能能做的是把框架摆清楚、把前提讲明白、把反例找出来；最后的选择仍然是你的。
