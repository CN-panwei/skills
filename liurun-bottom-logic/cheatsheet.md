# 速查表（Cheatsheet）

## 判断与归因

| 场景 | 规则 |
|---|---|
| 出了坏事，该怪谁 | 谁的损失大，就是谁的错；自己损失→怪自己→自己改变 |
| 跟人争论 | 先分清：事实（有真假）→观点（无对错）→立场（不争）→信仰（不碰） |
| 听到「为什么 X」 | 先问「X 是真的吗」，再决定是否回答 |
| 学一个非公理领域 | 兼听各家 + 找反例 + 记住前提 |
| 凭经验 vs 靠数据 | 问「样本是否被筛选过」（幸存者偏见） |

## 洞察与解决

| 层级 | 动作 |
|---|---|
| 结果层 | 改制度（处罚/奖励） |
| 原因层 | 改流程（优化步骤） |
| 模型层 | 改系统（重排连接关系）——顶级解法 |

分析问题五步：核心存量 → 关键因果链 → 增强回路 → 调节回路 → 滞后效应。

## 决策与概率

- 理性决策看**期望值**，不看单一结果。
- 20% 概率的事：做 14 次 → 95% 成功；做 21 次 → 99%。
- 概率四层权重：时代（千位，+12%）> 战略（百位，+5%）> 治理（十位，+2%）> 管理（个位，+1%）。
- 复利快检：期数真实吗？收益不靠利滚利吗？长期高收益存在吗？——三者都不过关，就不是复利是幻觉。

## 个人成长

| 杠杆类型 | 用法 | 风险 |
|---|---|---|
| 团队杠杆 | 复制知识库+方法论 | 依赖人才 |
| 产品杠杆 | 脱离边际交付时间 | 需要产品化能力 |
| 资本杠杆 | 用钱复制能力内核 | 需要控制权 |
| 影响力杠杆 | 演讲/写作/人脉 | 内核弱则加速失败 |

- 效率排序：选择（值不值得做）> 方法 > 工具。
- 时间颗粒度：越细越职业化；约会议按 30 分钟起步，守时按 1 分钟。
- 人脉：你能帮到的人才是人脉；数量 10-30-60。
- 学习：知识用脑（记）、技能用手（练）、态度用心（选）；别把知识当技能学，也别把技能当知识学。

## 定价与利润

| 价值类型 | 例子 | 稀缺度 |
|---|---|---|
| 功能价值 | 西瓜「甜得舍不得卖」 | 低（拼性价比） |
| 体验价值 | 半个西瓜送勺子 | 中（拼差异化） |
| 个性化价值 | 心形西瓜/红领定制 | 高（拼情感） |

利润三分：**趋势红利**（运气，会被拿走）→ **社会工资**（辛苦费）→ **创新利润**（别人学不会，唯一真利润）。

## 管理与激励

| 工作类型 | 激励方式 |
|---|---|
| 体力/计件工作 | 计件工资、KPI 可行 |
| 认知/创造工作 | 高固定工资 + 愿景；KPI 压抑创造力 |

- 共同体判断：涨薪 50% 愿意 → 利益共同体；降薪 50% 换 500% → 事业共同体；再投 500 万换 5000% → 命运共同体。
- 分钱总则：员工优先（固定）、老板劣后（剩余）；激励用分成；竞争优势小者拿固定。
- 治理 vs 管理：改变结果 < 改变原因 < 改变模型。

## 协作与规则

| 场景 | 法则 |
|---|---|
| 遇到野蛮人 | 自然法则（用力量/智慧保护自己） |
| 组织内部 | 族群法则（守规矩、利用规矩） |
| 组织之间 | 普遍法则（找共同点：尊重生命、契约精神） |

- 公平 = 同一把尺子；公正 = 谁有权选尺子；公开 = 过程展示 + 监督。
- 初次分配负责效率（支持老王），再分配负责公平（支持小张）；公平是下一个时代的红利。
- 信用是最大资产：储蓄靠言出必行，清空只需一分钟。

## 识别信号（Tells & Smells）

- 听到「为什么+观点」→ 有人在给你注射观点。
- 对方频繁迟到/临时改约 → 时间颗粒度太粗，或不够职业化。
- 行业人人能赚、利润越来越薄 → 赚的是趋势红利，正在被拉平成社会工资。
- 某公司天天喊忠诚度/企业文化留人 → 大概率处于「转型困境」，留不住优秀员工。
- 有人劝酒、让你拎包、「无理取闹」→ 服从性测试，先看清再回应。
- 只讲产品多好、不懂交易结构 → 用户思维/产品思维再强也可能输给系统。
- 「每天进步 1%」「7 年翻倍」→ 复利谬误套餐，逐一拆穿。
