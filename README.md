# skills

个人 AI 技能集合仓库。每个技能是一个独立的AI技能包，安装后可在各AI智能体中对话中自动触发或手动调用。

---

## 技能列表

### 1. one-person-business-assessor — 一人商业自我评估顾问

**解决什么问题：** 帮职场人完成从"螺丝钉思维"到"主权者思维"的清醒诊断。通过四坐标（时代→自我→商业→行动）系统性扫描：你现在在哪、你是谁、你能创造什么价值、你该从哪里开始。

**适用场景：**
- 有稳定工作但想做副业，不知道从哪开始
- 对自己能做什么感到迷茫，需要一次系统性诊断
- 想出来自己干但不清楚能不能养活自己
- 有几个模糊方向但不确定哪个值得投入

**一句话：** 帮你找到个人垄断市场，带着 24 小时内能执行的第一步离开。

### 2. ai-startup-strategist — AI 创业战略思维导师

**解决什么问题：** AI 时代创业的三个特有陷阱——构建了没人要的东西、AI 写得太快导致功能失控、团队规模惯性。通过三阶段（想法验证→MVP 构建→增长规模化）帮创始人做清醒的战略决策。

**适用场景：**
- 有一个创业想法但不确定值不值得做
- 在 MVP 阶段不断被新功能分散注意力，需要范围裁剪
- 团队效率遇到瓶颈，需要诊断自动化空间
- 担心产品护城河不够深

**一句话：** AI 创业版的恶魔代言人——不鼓励你，只帮你找出想法里最致命的问题。

### 3. one-person-business-advisor — 一人商业定位顾问

**解决什么问题：** 当你已经决定要做自媒体/一人公司，但卡在"我的定位到底是什么"这一步。通过三阶段（残酷解构→刺猬交叉→MVP画布），用苏格拉底式追问帮你找到只有你能占据的内容生态位。

**适用场景：**
- 已经开始做内容/产品，但感觉没有差异化
- 有专业技能但不知道怎么变成有穿透力的内容定位
- 同时有几个方向，不知道该砍哪个
- 想做个人 IP 但不想跟别人卷同一个赛道

**一句话：** 一把手术刀——切开你的自我叙述，找到痛苦×技能×变现路径的真正交叉点。

基于 Alex Hormozi 方法论构建的商业策略系统，将 Hormozi 的报价、获客、定价框架编码为可执行的 AI 工作流。

### 5. super-individual-positioning — 超级个体自我认知与定位系统

**解决什么问题：** 用恶魔代言人角色帮你打破自我认知幻觉。融合德鲁克（回馈分析法）、纳瓦尔（特定知识）、柯林斯（刺猬理论）、克拉克（个人商业模式画布）四位思想家的框架，通过四模块流水线（外部反馈→基因挖掘→收敛定位→商业模式落地）系统性地回答：你现在在哪、你是谁、你能创造什么价值、你该从哪里开始。

**适用场景：**
- 完全不知道自己的方向在哪，需要一次系统性自我诊断
- 有几个模糊方向但不确定哪个值得投入
- 对自己「擅长什么」「热爱什么」的自我认知需要外部校准
- 想从螺丝钉思维切换到主权者思维，但不知从哪里开始

**一句话：** 不提供鸡汤，只提供镜子——用数据和追问戳破你对自己的幻觉，找到只有你能占据的生态位。

### 6. world-cup-analyzer — 世界杯 AI 分析器

**解决什么问题：** 普通 AI 回答世界杯问题信息零散、没有评分标准。本技能定义了标准化的数据采集流程、TCR（球队综合实力指数）和 MCR（单场综合评分）双评分体系，让世界杯相关查询从「闲聊」升级为「结构化分析报告」。

**适用场景：**
- 查比分、积分榜、赛程等实时数据
- 分析某支球队的综合实力（TCR 六维度拆解）
- 评价某场比赛的精彩程度（MCR 五维度评分）
- 对比两支球队或与历届球队做横向对比
- 查射手榜、助攻榜等球员数据

**一句话：** 把世界杯数据查询和分析编码为 AI 技能——双评分体系让评价有据可依，多源交叉验证让数据可信。

### 7. enterprise-management-master — 企业经营管理大师

**解决什么问题：** 多数小企业的瓶颈不是"管理能力不够"，而是所有决策都经过老板这个节点。这个技能不讨论领导力、不讨论怎么"管得更好"——只关注一件事：规则和系统怎么替代老板在现场做决策。融合塔勒布（风险收益对称性）、格伯 E-Myth（三种角色分离）、高德拉特 TOC（瓶颈约束理论）、稻盛和夫（阿米巴核算）四人的核心洞见。

**适用场景：**
- 什么事都要你拍板，想放权放不下去
- 刚开始创业，想从一开始就建对管理系统
- 业务做大了，原来的管法管不住了
- 想从一线操作里抽出来，转向建造系统
- 员工不操心成本和利润，只有你在操心
- 有合作方但规则是口头约定，想建立书面规则又怕伤感情

**一句话：** 系统建造教练——帮你从"最好的员工"转型为"系统建造者"，最终让业务不需要你也能运转。

### 8. wwg-thinking-tools — 万维钢思维工具实战陪练

**解决什么问题：** 万维钢《现代思维工具100讲》讲得散、没时间读成体系。这个技能把全课 116 个讲次条目做成知识库，并配一套五步对话协议：先用你的真实处境补齐关键事实（目标函数、硬约束、时间尺度、可承受损失、判断标准），再调用 2–4 个**视角真正不同**的思维工具并置分析，把工具之间**打架的地方**指出来，最后回扣到课程原讲（讲次编号 + 机制 + 最反直觉的一点 + 最常见的误用）。一次对话 = 解决一件事 + 学会两三讲。

**适用场景：**
- 职业岔路口：该留下还是换赛道／换城市，同类人的结果分布是什么样的
- 一个决定拿不准：该不该下注、下多大，会不会撞上"吸收壁"
- 中年方向感：找不到兴趣点，也不知道该把什么做成事业
- 组织与团队难题：新 KPI 一上大家就刷数据，能人一堆却协作不起来
- 学习与教育：读了很多书还是不会用，孩子学习没动力
- 赚钱与商业模式：想做点生意不知道做什么，"凭什么是我赚钱"
- 社会与规则：政策规则总在变，不敢做长期投入
- 意义与人生：钱够花了但不知道为什么要起床，越想幸福越不幸福

**一句话：** 不打鸡血的陪练——把你的难题摆上桌，用万维钢的 116 讲当工具箱切它，顺便把课学了；工具结论冲突时它不调和，直接告诉你分水岭在哪。

### 9. liurun-bottom-logic — 底层逻辑（刘润）知识库

**解决什么问题：** 很多商业和管理问题不是"想得不够多"，而是**看错了层**——在结果层反复救火，却没动过产生结果的那个结构。这个技能把刘润《底层逻辑：看清这个世界的底牌》5 章拆成可调用的框架，按你的问题定位到对应章节：出了事该怪谁（三种对错观）、问题为什么反复发生（系统五模块、改变结果<原因<模型）、怎么更快变强（人生商业模式 = 能力×效率×杠杆）、为什么讲不通（What/Why/How 三问、边界感）、我赚的到底是什么钱（趋势红利／社会工资／创新利润、稀缺决定分配权）。可带主题词或章节号 `ch01`–`ch05` 精准加载。

**适用场景：**
- 出了事要定责：这到底是谁的错，该怪人还是怪结构
- 问题反复出现、制度改了几版还是没用，需要看清系统
- 说服不了人、开会总扯皮，或被人用「为什么+观点」带节奏
- 个人成长卡住：很忙但没长进，该先补能力还是先上杠杆
- 赛道选择：该做产品还是做服务，怎么不再靠出卖时间赚钱
- 定价与利润：同行都在降价要不要跟，我赚的是利润还是辛苦费
- 分钱与激励：固定工资、奖金、股权怎么配，为什么加了 KPI 反而更差
- 协作与博弈：跟不讲理的人怎么打交道，合伙规则怎么谈，劝酒这类事怎么识别

**一句话：** 一套"先看层、再看事"的诊断工具——用三种对错观定责、用系统五模块找结构、用稀缺性判断你值多少钱；另附速查表和识别信号，能当场认出别人在给你注射观点或做服从性测试。

### 10. classical-wisdom-practice — 中国古典智慧实践

**解决什么问题：** 经典读得懂却用不上——嘴上说"知行合一"，事到临头还是拖延；知道"知彼知己"，做决定时照样拍脑袋。这个技能不做经典科普，而是按**问题类型**把六部经典匹配到你的处境：《孙子兵法》＋《中庸》管决策，《论语》＋《孟子》＋《传习录》管修养，《大学》＋《孟子》管管理，《中庸》＋《孙子兵法》解两难。匹配完再走四步固定流程——场景匹配 → 自我反思自检（决策前五问／行动后四问）→ 行动建议（带时间节点）→ 复盘巩固。

**适用场景：**
- 面临选择：要不要跳槽、接不接新岗位、跟不跟这个人合作，需要先做一次"庙算"
- 两难困境：两个选项各有各的道理，想找超越二元对立的第三选择
- 日常修养：想建立每日修身习惯，但不知从何开始、也坚持不下来
- 团队管理：士气低落、效率下降，需要从"正心"和规则入手而不是靠吼
- 道德困境与意志磨炼：该不该做一件"对但难"的事，扛不扛得住压力
- 行动落地：道理全懂就是不做，需要"事上磨练"的具体安排
- 情绪与关系失衡：太刚易折、太软受欺，想找那个"度"在哪

**一句话：** 带着你的真实问题来就行——它负责把六部经典翻译成你 24 小时内能迈出的第一步，以及什么时候该回头复盘；不给你"三思而后行"这种正确但没用的答案。

### 11. economic-thinking-framework — 经济学思维操作系统

**解决什么问题：** 大多数决策失误不是信息不够，而是**没看清代价和激励**——只算看得见的支出，不算放弃掉的最好选项；指望人靠善意做事，不看他们实际面对什么激励。这个技能把经济学从"研究钱的学科"还原成一套**稀缺性约束下的决策操作系统**，用四层架构逐层往下切：L1 问题重构（真正的约束是什么、你愿意为此放弃什么）→ L2 机制识别（谁有激励做什么、博弈结构是什么）→ L3 推演取舍（边际收益在哪拐弯、次优解是什么）→ L4 制度审视（规则本身是否扭曲了激励）。底层是 7 个心智模型：机会成本、激励相容、交易成本、知识分散与自发秩序、可信承诺、边际分析与次优、路径依赖，另配 9 条决策启发式。

**适用场景：**
- 有人跟你说"这是免费的""这是为你好"，想判断代价被藏到哪去了
- 制度、政策、流程推不动或一推就歪，想画一张激励地图找原因
- 两个方案各有各的道理，需要先把各自的放弃项算清楚
- 组织里"该做的人没激励、有激励的人不该做"，考核改了几版还是变形
- 想验证一个常识判断（限价、租金管制、最低工资这类"好心办坏事"）
- 判断一个承诺可不可信、一个合作能不能长久
- 想理解为什么明显低效的规则却改不动

**一句话：** 一套"先算代价、再看激励"的校验器——它不直接给结论，而是先追问"你放弃了什么""谁有激励做什么"，专治被显性好处带偏的判断；碰到非理性行为、制度锁定、公平与可行能力这三类它自己承认搞不定的问题，会主动亮出卡尼曼／西蒙、诺斯、森的补充视角。

## 推荐使用路径

### 创业者路径（实体经营/管理需求）

```
阶段一：企业经营管理大师（enterprise-management-master）
    │  从零路线图：合作规则 → 预算 → 价值流 → 脆弱点 → 核算 → 退出
    │  或四步工作流：诊断 → 定位 → 共建 → 输出
    │  输出：具体规则 + 核算方式 + 退出时间表
    │
    └─ 需要自媒体推广业务 ──► 一人商业定位顾问（advisor）
                                   聚焦内容生态位和获客策略
```

### 自媒体/一人公司路径

对于一个**完全没想法、没行动的人**，按以下路径使用：

```
阶段一：一人商业自我评估顾问（assessor）
    │  四坐标扫描：时代→自我→商业→行动
    │  输出：你在哪、你是谁、你能做什么
    │
    ├─ 发现自己有创业想法 ──► 阶段二：AI 创业战略顾问（strategist）
    │                              │  验证想法、定义 MVP、构建护城河
    │                              │
    │                              └─ 需要自媒体定位 ──► 阶段三：一人商业定位顾问（advisor）
    │                                                       聚焦内容生态位、受众、首发切入点
    │
    ├─ 发现自己更适合一人公司/自媒体 ──► 直接进入阶段三：一人商业定位顾问（advisor）
    │
    └─ 发现自己还没准备好 ──► 回去积累经历、获取市场反馈，再回来
```

**已有方向/成果的人**，可以跳过前面的技能，直接进入对应阶段。

### 通用思考路径（不限于商业，任何真实难题）

从上面两条路径走出来之后，真正卡住你的往往不是"该做什么生意"，而是**具体处境怎么判断**——该不该换赛道、该不该 all in、团队为什么出不了活、规则总变怎么决策。这些都可以交给万维钢思维工具实战陪练：

```
万维钢思维工具实战陪练（wwg-thinking-tools）
    │  五步协议：补齐事实 → 匹配工具 → 并置分析 → 综合与张力 → 回扣课程
    │  九个视角池：认知自我 / 证据概率 / 下注风险 / 时间位置 /
    │             学习能力 / 激励制度 / 组织权力 / 系统演化 / 意义统摄
    │  输出：推荐动作 + 决策判据 + 什么新证据会改变结论 + 用到的讲次
    │
    ├─ 需要先把方向定下来 ──► 回上面两条路径（定位顾问 / 战略顾问）
    │
    └─ 需要把系统搭起来 ──► 企业经营管理大师（enterprise-management-master）
```

它自带 43 条「处境 → 工具组合」映射，所以你不用知道该用哪个工具，把处境讲清楚就行。

### 诊断路径（看错了层、或不知道该看哪层）

当你已经知道要做什么，但**判断总是偏**——出了事找不到真正的责任人、制度改了三次还是没用、被人一句话带偏——问题往往不在信息量，而在看问题的层次。这时用刘润的底层逻辑框架做一次诊断：

```
底层逻辑（liurun-bottom-logic）
    │  按问题定位章节：定责 → ch01 ／ 看清系统 → ch02
    │                  个人成长 → ch03 ／ 沟通理解 → ch04
    │                  赚钱分钱 → ch05
    │
    ├─ 判断"这事谁的错、我该怪谁" ──► ch01 三种对错观 + 课题分离
    ├─ 判断"为什么反复发生、该改哪层" ──► ch02 系统五模块 + 改变三层
    ├─ 判断"我赚的是利润还是辛苦费" ──► ch05 利润三分 + 稀缺决定分配权
    │
    └─ 想快速查规则或识别套路 ──► 直接要速查表（cheatsheet）
```

它自带主题词与章节号两种调用方式（`/liurun-bottom-logic 定价`、`/liurun-bottom-logic ch05`），不需要你先把书读完。

### 修养与决策路径（古典智慧）

前面几条路径解决的都是"想清楚"。但想清楚之后，**真正卡住人的常常是动不了**——明知该放权还是忍不住插手，明知该止损还是拖，明知该闭嘴还是一句话怼了回去。这类问题不是信息不够，而是"知"与"行"之间断了。这时用中国古典智慧实践做一次校准：

```
中国古典智慧实践（classical-wisdom-practice）
    │  按问题类型匹配经典：决策 → 孙子兵法＋中庸 ／ 修养 → 论语＋孟子＋传习录
    │                      管理 → 大学＋孟子 ／ 两难 → 中庸＋孙子兵法
    │  四步流程：场景匹配 → 自检（决策前五问／行动后四问）→ 行动建议 → 复盘巩固
    │
    ├─ 要先算胜算再下注 ──► 《孙子兵法》五事七计 + 庙算：彼、己、天、地、法
    ├─ 两个选项都不满意 ──► 《中庸》执其两端用其中：找超越二元对立的第三选择
    ├─ 道理都懂就是不做 ──► 《传习录》知行合一 + 事上磨练：从具体事务里修
    ├─ 该不该做"对但难"的事 ──► 《孟子》义利之辨 + 浩然之气
    │
    └─ 想快速查框架 ──► 直接要速查表（cheatsheet）
```

它的输出必须落到时间表上：即时行动（24 小时内做什么）→ 短期计划（1–4 周）→ 复盘节点（何时回头检验），所以不会停在一句"你要修身"。

---

### 经济学视角路径（算清代价与激励）

前面几条路径都在帮你判断"该做什么"。但方案定下来之后，还有一类错误专门埋伏在**代价和激励**里：只算看得见的成本，不算放弃掉的最好选项；设计规则时假定大家会按你的意图行事，结果一上线就被真实激励扭曲。这时用经济学思维操作系统做一次校验：

```
经济学思维操作系统（economic-thinking-framework）
    │  四层架构：L1 问题重构 → L2 机制识别 → L3 推演取舍 → L4 制度审视
    │  七个模型：机会成本 ／ 激励相容 ／ 交易成本 ／ 知识分散与自发秩序 ／
    │            可信承诺 ／ 边际分析与次优 ／ 路径依赖与制度锁定
    │
    ├─ 有人说"这是免费的" ──► 机会成本：被隐藏或转嫁的那部分代价是什么
    ├─ 规则一上线就变形 ──► 激励相容：谁有激励做什么，谁该做却没有激励
    ├─ 这个承诺靠得住吗 ──► 可信承诺与博弈结构：可信度来自结构，不来自表态
    ├─ 该继续加码还是收手 ──► 边际分析与次优：边际收益在哪里拐弯
    ├─ 明显低效却改不动 ──► 路径依赖：找出锁定的那条历史路径
    │
    └─ 想快速自检 ──► 直接要决策检查清单（manual 第 7 节）
```

它承认自己的边界：涉及非理性行为、制度锁定、公平与可行能力时，会切到卡尼曼／西蒙、诺斯、森的补充视角，不把"人会按激励行动"当万能公式。

## 安装方法

### 前置条件

- 已安装 [Claude Code](https://claude.ai/code)（VS Code 扩展、JetBrains 扩展或 CLI）
- 克隆本仓库到本地

### 安装单个技能

创建符号链接到 Claude Code 技能目录，修改后即时生效：

```bash
# 克隆仓库
git clone <repo-url> ~/skills-repo

# 创建符号链接（以 one-person-business-advisor 为例）
ln -s ~/skills-repo/one-person-business-advisor ~/.claude/skills/one-person-business-advisor
```

### 安装所有技能

```bash
for dir in ~/skills-repo/*/; do
  skill_name=$(basename "$dir")
  if [ "$skill_name" != ".git" ]; then
    ln -s "$dir" "$HOME/.claude/skills/$skill_name"
  fi
done
```

安装后重启 Claude Code 或开始新对话即可在技能列表中看到已安装的技能。

### 调用技能

- **自动触发：** 用自然语言描述你的需求，技能会根据描述自动触发
- **手动调用：** 输入 `/<技能名称>`，如 `/one-person-business-advisor`
