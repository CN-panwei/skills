# 💬 使用示例

下面是触发本技能的常见提问模板，覆盖了 8 大场景：

## 1️⃣ 查比分

```
昨晚阿根廷对法国比分多少？
德国 1-0 西班牙 那场球谁进的？
今天凌晨的比赛结果？
```

## 2️⃣ 查积分 / 出线形势

```
C 组积分榜
B 组出线形势怎么样？
阿根廷已经出线了吗？
```

## 3️⃣ 查赛程

```
今天有什么比赛？
明天晚上几点有比赛？
1/4 决赛对阵表
```

## 4️⃣ 球队分析（TCR）

```
巴西队 TCR 多少？实力怎么样？
分析一下法国队
这届德国队和 2014 年那支比怎么样？
```

## 5️⃣ 比赛评分（MCR）

```
评价一下德国 vs 日本那场
葡萄牙 3-2 加纳 那场精彩吗？
昨晚那场球值多少分？
```

## 6️⃣ 球员数据

```
射手榜
姆巴佩这届进了几个？
助攻榜
```

## 7️⃣ 历史对比

```
这届阿根廷和 1986 年那支比
2014 德国和 2022 德国 哪个强？
```

## 8️⃣ 综合报告

```
出个世界杯全面报告
这届世界杯总结一下
```

---

## 🛠️ 进阶用法

### 限定时间窗口

```
"过去 24 小时的世界杯新闻"
"过去一周各队状态"
```

### 多维度交叉

```
"小组赛所有爆冷比赛的 MCR"
"TCR 前 8 名的球队和小组赛对手对比"
```

### 自定义权重（高级）

直接在提问中说明你的偏好：
```
"用更看重近期状态的 TCR 公式评一下巴西"
"评价时侧重戏剧性"
```
