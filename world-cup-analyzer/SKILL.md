# World Cup Analyzer

## 意图解析

拿到用户提问后，先分类到以下场景之一：

| 场景 | 关键词/模式 | 输出 |
|------|-----------|------|
| 查比分 | "XX对YY比分"、"昨晚比赛结果" | 比分表格 + 关键事件 |
| 查积分 | "小组积分"、"XX组排名"、"出线形势" | 小组积分表 + 出线分析 |
| 查赛程 | "今天有什么比赛"、"赛程" | 赛程时间线 |
| 球队评分 | "XX队怎么样"、"XX队实力"、"分析XX队" | TCR 完整报告 |
| 比赛评分 | "XX对YY好看吗"、"评价一下XX那场" | MCR 完整报告 |
| 球员数据 | "射手榜"、"XX表现怎么样"、"助攻榜" | 球员统计表 |
| 综合报告 | "出个报告"、"全面分析" | TCR + MCR + 积分 + 赛程 |
| 对比 | "和上届比"、"XX和YY对比"、"和2014年XX队比" | 并排对比报告 |

不确定意图时，默认走「综合报告」+ 追问澄清。

## 数据采集

### 源列表（按并行搜索）

每次查询至少触发 3 个来源做交叉验证：

**中文源：**
- 懂球帝 dongqiudi.com — 比分、积分、新闻
- 直播吧 zhibo8.cc — 赛程、即时比分
- 虎扑体育 hupu.com — 球员评分、讨论

**英文源：**
- FIFA 官网 fifa.com — 官方赛程/积分（权威源）
- ESPN espn.com — 比分、统计、新闻
- Transfermarkt transfermarkt.com — 身价、球员数据
- SofaScore / Flashscore — xG、详细统计

### 采集流程

```
用户提问 → 解析意图 → 确定需要哪些维度（身价/xG/积分/赛程）
         → 并行 WebSearch 3-4个源
         → 关键数据点 WebFetch 深挖（如需要详细统计）
         → 交叉验证：至少2个源一致才采用
         → 评分计算
         → 中文输出
```

**重要：** 搜索结果有时效性。如果搜索返回的数据明显过时，提示用户"以下数据截至 X月X日，实时数据建议打开官方源确认"。

## TCR — 球队综合实力指数

百分制，满分 100。每项先评原始分（0-100），再加权求和。

### 公式

```
TCR = 25% × 阵容战力 + 20% × 近期状态 + 20% × 战术执行
    + 15% × 赛果含金量 + 10% × 关键球员 + 10% × 赛程负荷
```

### 各维度评分标准

**阵容战力（25%）**
- 转会市场全队身价在该赛事所有球队中的百分位排名 → 线性映射到 [0, 100]
- 若无身价数据，用 FIFA 世界排名替代
- 考虑：世界级球星数量（身价 > 8000万欧）、五大联赛主力占比

**近期状态（20%）**
- 近 5 场战绩：胜 = 100，平 = 50，负 = 0，指数衰减加权（越近权重越高：0.30, 0.25, 0.20, 0.15, 0.10）
- 近 5 场净胜球趋势加分（±5）
- 连续不败/连胜额外加分（3连胜 +5，5连胜 +10）

**战术执行（20%）**
基于可用数据综合判断：
- 控球率（与对手对比）— 不只是高，要看有效性
- xG（预期进球）vs 实际进球 — 转化效率
- xGA（预期失球）vs 实际失球 — 防守质量
- 传球成功率、关键传球数
- 压迫效率（前场夺回球权次数）

**赛果含金量（15%）**
- 对手 TCR 加权：赢 TCR≥80 的队 = 100分价值，赢 TCR<40 的队 = 30分价值
- 净胜球调整：净胜 3+ 球 ×1.2，点球获胜 ×0.8
- 场次重要性：淘汰赛 ×1.5，小组关键战 ×1.2

**关键球员（10%）**
- 核心球员伤停：-20～0
- 球星当前状态（近期俱乐部/国家队表现）
- 是否有球员在射手榜/助攻榜前列
- 门将实力（扑救成功率）

**赛程负荷（10%）**
- 剩余对手平均 TCR — 越低分越高（赛程轻松）
- 距下一场比赛天数 — 3天以下减分
- 旅途/场地因素
- 已确定出线/已淘汰 → 后续战意调整

### TCR 分级

| 分数 | 标签 | 含义 |
|------|------|------|
| 90-100 | 🔥 冠军级 | 夺冠大热 |
| 80-89 | ⭐ 争冠级 | 四强候选 |
| 70-79 | 💪 淘汰赛级 | 稳定出线，有黑马潜质 |
| 55-69 | 👀 搅局者 | 小组出线有悬念 |
| 40-54 | 📉 陪跑级 | 出线希望渺茫 |
| < 40 | 🏠 观光级 | 提前准备回家 |

## MCR — 单场综合评分

百分制，满分 100。用于评价一场已完成的比赛。

### 公式

```
MCR = 30% × 竞技质量 + 25% × 战术博弈 + 20% × 戏剧性
    + 15% × 个人高光 + 10% × 赛事意义
```

### 各维度评分标准

**竞技质量（30%）**
- 两队技战术水平展现（不能一边倒）
- 攻防节奏、比赛流畅度
- 失误控制（非受迫失误少 → 高分）
- 射门质量（射正率、精彩扑救）

**战术博弈（25%）**
- 双方阵型变化和临场调整
- 针对性部署是否有效
- 换人效果
- 教练决策水平（时机、人选）

**戏剧性（20%）**
触发即加分：
- 逆转获胜 +15
- 补时绝杀/绝平 +20
- 红牌/争议判罚 +10
- 冷门（低 TCR 方胜高 TCR 方）+15
- 点球大战 +10
- 单场进球 ≥ 5 +10
- 零封强队 +5

**个人高光（15%）**
- 帽子戏法 +20
- 梅开二度 +10
- 单场助攻帽子戏法 +15
- 门将神扑（扑救 ≥ 5 次且保持零封）+10
- 新星爆发/名场面 +10

**赛事意义（10%）**
- 决赛 100
- 半决赛 90
- 1/4 决赛 80
- 1/8 决赛 70
- 小组出线关键战 65
- 德比/宿敌 75（可叠加）
- 普通小组赛 40

### MCR 分级

| 分数 | 标签 | 含义 |
|------|------|------|
| 90-100 | 🏆 经典 | 必看，世界杯历史留名 |
| 80-89 | 🔥 名局 | 本届最佳候选 |
| 65-79 | 👍 好球 | 值得看回放 |
| 45-64 | 👌 尚可 | 球迷可看，路人可跳过 |
| < 45 | 💤 催眠 | 集锦都不用看 |

## 对比规则

当用户要求与历史球队对比时（如"这届德国和2014年德国比"）：

1. 先评当前队伍 TCR
2. 搜索历史队伍数据（维基百科/FIFA 档案）
3. 用统一标准为历史队伍评 TCR
4. 并排对比 + 差异分析
5. 标注历史数据局限性

**对比项**：阵容身价（经通胀调整）、场均进球/失球、xG（如有）、关键球员对比、教练对比

## 注意事项

- **数据时效性**：比赛日每 3-4 小时数据有明显变化，非比赛日可日更。如果上次采集超过 6 小时，提醒用户数据可能需要刷新。
- **数据冲突**：多个源数据不一致时，以 FIFA 官方 > ESPN > 懂球帝 的优先级为准，并在输出标注来源。
- **评分主观性**：战术执行、个人高光等维度存在主观判断空间。给出评分时简述理由，让用户能自行判断是否同意。
- **不要编造**：如果某维度数据搜索不到（比如某场 xG 还没出），标注"数据暂缺"并用其他维度替代推算，不要凭空给分。
- **中文表达**：输出全部中文，队名用中文习惯称呼（巴西、德国、阿根廷，不用 Brazil/Germany），球员名保留原文（Mbappé、Messi）不音译。
