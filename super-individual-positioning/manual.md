# 超级个体自我认知与定位系统 · 用户手册

> 使用方法：复制你想问的问题，粘贴给 Claude。技能会自动激活。

## 功能模块说明

### M1：外部反馈校准 ——「你以为的优势，可能只是自我感动」

**模块作用**：用客观数据和他人视角打破自我认知盲区。核心工具是德鲁克回馈分析法（在结果出现前写下预期，事后对比差异）和结构化外部反馈问卷。

**你获得什么**：经过外部校准的自我认知基线——知道「别人眼中的我」和「我眼中的我」之间的差距在哪。

### M2：基因挖掘 ——「那些对你像玩一样的事情，可能你根本没当回事」

**模块作用**：挖掘你不可复制的独特组合。核心工具是特定知识四层自测（童年线索→成人"玩感"检测→非对称经历盘点→交叉验证）和技能叠加矩阵。

**你获得什么**：一份「个人基因图谱」——你做起来轻松但别人觉得难的认知活动、你独特的人生经历组合、以及2-3个可能的技能叠加方向。

### M3：收敛定位 ——「三圈交集帮你排除90%的选项」

**模块作用**：从一堆可能方向中收窄到1-2个聚焦方向。核心工具是三圈交集工作表（热情圈×天赋圈×经济引擎圈）和热情真伪检测。

**你获得什么**：通过了热情（真热爱还是爱结果？）、天赋（有编码还是只是做了很久？）、经济引擎（谁愿意付钱？）三重检验的定位方向。

### M4：商业模式落地 ——「不能变现的定位是高级消费，不是事业」

**模块作用**：将定位方向转化为可执行的个人商业模式。核心工具是个人商业模式画布（9个模块——价值主张、客户细分、收益来源、渠道、客户关系、关键资源、关键活动、关键伙伴、成本结构）。

**你获得什么**：一张没有空白的个人商业模式画布，特别是「最危险假设」——如果它错了，你的定位需要重新考虑。

## 适用场景

### 场景1：完全迷茫 ——「我不知道自己能做什么」

你不知道自己擅长什么，不知道往哪个方向发展。你甚至不确定自己有没有优势。

**建议路径**：从M1开始——先让外部反馈告诉你关于自己的你不知道的事。不要跳过这一步在脑中继续空转。

### 场景2：有想法但不自信 ——「我有几个方向但不确定哪个对」

你有一些兴趣方向或想法，但不确定：这会不会只是自嗨？别人真的会付钱吗？我够不够格？

**建议路径**：从M2开始——先把你已有的想法放入基因挖掘的工具中检验。M1的外部反馈作为补充校准，看看别人眼中的你和你以为的你之间有没有差距。

### 场景3：有明确方向想验证 ——「我觉得我的定位应该是X」

你有一个比较清晰的想法，但不确定：这个方向能不能持续？会不会很快就倦怠？市场真的存在吗？

**建议路径**：从M3开始——把你的想法放入三圈交集检验。特别注意热情真伪检测（枯燥测试、赞美戒断测试）。然后用M4的画布检查致命模块。

### 场景4：正在做但想转型 ——「我现在做的事没热情了，想换个方向」

你已经有收入、有受众、有作品积累——但感觉这不是你真正该做的事。担心已经到了burnout边缘。

**建议路径**：从M3开始——重新审视热情圈（特别是能量方向测试）。但不要急着丢掉现有的经济引擎圈。从M1重新收集外部反馈，也许问题不在方向，在执行节奏或成本结构。

### 场景5：已有方向想做成可持续模式 ——「我知道做什么，但不知道怎么赚钱/持续」

你已经有了定位方向，但收入不稳定、或不可持续、或不知道如何规模化。

**建议路径**：直接从M4开始——画布九模块。重点关注「收益来源多样性」和「成本结构可持续性」。M3的三圈交集做快速复查（确认没漏掉哪圈）。

### 场景6：想做一人公司/超级个体 ——「我想独立做，不打工了」

你想从打工人转型为独立创作者/咨询师/一人企业老板，但不确定：从哪里开始？卖什么？卖给谁？

**建议路径**：完整走M1→M2→M3→M4全流程。不要跳过M1（外部反馈对你而言尤其重要——别人愿意为你付钱的事，可能和你以为的完全不同）。

## 预设问题库

以下问题按场景分组，**只含问题不含答案**。直接复制使用。

### 入口问题（任何场景都可从这里开始）

```
帮我做自我认知和定位分析。我目前的状态是[选一个：
完全没方向 / 有几个想法但不确定 / 有明确方向想验证 /
正在做但想转型 / 想做一人公司还没开始]。
```

### 场景1 问题组：完全迷茫

```
我觉得自己什么都一般，没什么特别擅长的，也没什么方向。
能帮我从这个状态开始做定位分析吗？
```

```
我不知道自己对什么有热情。以前感兴趣的事做到一半就不想做了。
怎么区分"真热情"和"三分钟热度"？
```

```
我总觉得自己没有不可替代的优势。别人都能做的事，我不知道为什么别人应该选我。
```

```
怎么知道别人眼中的我和我以为的我之间的差距？我应该问谁？问什么？
```

```
我觉得我需要先找到天赋再开始行动，但一直找不到。
是不是顺序反了？还是我有什么盲区？
```

```
我做过很多不同的事情，但没有一件做到很深。
这种"什么都会一点"的状态，能转化成优势吗？
```

```
我很羡慕那些从小就知道自己要做什么的人。
我三十多岁了还不知道——正常吗？还是我错过了什么？
```

### 场景2 问题组：有想法但不自信

```
我有几个感兴趣的方向，但我不知道哪个是"真喜欢"还是"假兴奋"。
能帮我检验一下吗？我的方向是：[描述你的几个方向]
```

```
我想做[方向]，但我担心这只是自嗨——我会不会做了一段时间后发现根本没人需要？
```

```
别人说我[某种能力]还不错，但我不确定他们是在客气还是真心。
怎么判断？
```

```
我想做[方向A]但我觉得市场上已经有很多人在做了，我进去会不会太晚？
怎么判断一个赛道还有没有空间？
```

```
我感兴趣的方向（[A]）和能赚钱的方向（[B]）完全不一样。
应该选哪个？还是能结合？
```

```
我对[A]有热情，但我没有相关经验和技能。我是应该先去学习，还是直接开始做？
```

```
我怕自己选错了方向浪费几年时间。有没有什么低成本的方式可以先验证？
```

### 场景3 问题组：有明确方向想验证

```
我的定位是[描述你的定位]。帮我用三圈交集（热情×天赋×经济引擎）来检验这个方向。
```

```
我想做[方向]。怎么判断我是真的热爱这件事本身，还是热爱做成了之后的认同感？
```

```
我找到的方向同时满足了热情和天赋，但不确定能不能变现。
谁愿意为这个付钱？怎么验证？
```

```
我的方向能找到付费的人，我也算擅长，但我怕做久了会倦怠。
怎么判断这个方向的"成本可持续性"？
```

```
我找到了两圈的交集（[描述哪两圈]），但第三圈是空的。
这种情况应该怎么办？继续找还是先做两圈的？
```

```
我怕定了方向之后发现是错的。但一直不定方向又什么都推进不了。
有没有在"探索"和"聚焦"之间平衡的方法？
```

### 场景4 问题组：正在做但想转型

```
我现在做[当前方向]，收入还行，但我没有热情了。
怎么判断是该坚持还是该换方向？
```

```
我做[当前方向]感觉自己越来越被消耗。但不确定这是方向的问题，
还是我自己节奏/成本结构的问题。能帮我诊断吗？
```

```
我有个想转的方向（[新方向]），但不敢完全放弃现在有收入的方向。
有没有办法在两条轨道上同时跑？
```

```
我在现有方向积累了一些资源和受众，转型的话这些积累会不会全丢掉？
能不能带上现有的东西？
```

```
我现在的方向感觉不是"我"——但我也不知道什么才是我。
怎么从现有轨道上后退一步，重新做自我认知？
```

### 场景5 问题组：有方向想做可持续模式

```
我有了明确的定位方向（[描述]），但不知道怎么从"有方向"
变成"有收入"。能帮我画一张个人商业模式画布吗？
```

```
我的收入主要来自[来源]，太单一了。怎么设计多元收入结构？
```

```
我做[方向]，每周大概工作[X]小时。怎么判断这个时间投入是否可持续？
隐性成本（精力、情绪、关系损耗）怎么计算？
```

```
我的价值主张是"[描述]"。我自己觉得很清楚，但总有人问我"你到底做什么的"。
怎么让价值主张更清晰？
```

```
我的定位方向我很确定，但不知道能走多大。怎么判断这个方向的天花板？
```

```
我有了画布，但不知道先从哪里开始改。画布里哪个模块错了影响最大？
```

### 场景6 问题组：想做一人公司/超级个体

```
我想从打工人转型为独立创作者，但不确第一步该做什么。
能带我完整走一遍M1→M4的定位流程吗？
```

```
我想做一人公司，但我发现我只会"创作"，不太会"经营"。
这两部分怎么分配精力和时间？
```

```
我现在有全职工作，想一边工作一边准备独立出来。在这种"双轨"状态下，
怎么做好自我定位？时间精力有限，先做什么？
```

```
我想独立做，但我担心：没有同事、没有稳定工资、没有人给我反馈，
这种状态我能撑多久？
```

```
我看了很多一人公司的案例，但越看越纠结——好像每条路都有人走过了，
我怎么找到只有我能做的那个交叉点？
```

```
我想做[方向A]但我看到平台上的头部创作者收入很高、
方向类似——我怎么和他们差异化？
```

```
我确定了[定位方向]，准备开始了。但AI工具越来越强，
我怕我做的东西很快会被AI替代。这个方向真的选对了吗？
```

### 深度追问（在流程中穿插使用）

```
你刚说我"擅长X"——过去6个月有什么客观数据支撑吗？
有没有反例？
```

```
你觉得你热爱[某件事]——你做这件事时最枯燥、最无聊的部分是什么？
你愿意做那部分吗？
```

```
如果把你定位描述里的关键词换掉，能不能套在另一个从业者身上？
如果能，你的差异化在哪？
```

```
你当前的投入节奏——每周几小时、什么精力水平——在6个月尺度上可持续吗？
```

```
假设两年后你的定位彻底失败。写下5个最可能的原因。
最危险的假设是什么？
```
