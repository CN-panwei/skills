# 万维钢思维工具实战陪练 — 使用手册

> 使用方法：把你正在发愁的那件事直接讲出来，技能会自动激活。不用背工具名，也不用先想清楚问题——想不清楚本身就是它要帮你处理的第一步。

---

## 这个技能在做什么

它不是《现代思维工具100讲》的课程检索器，而是**用你的真实处境当入口的陪练**。

判断标准只有两条：

1. 一轮对话结束，你比开始时更清楚**该看什么、该做什么、什么证据会推翻当前判断**；
2. 你至少真的理解了两三个思维工具——能说出它们的机制、边界和**彼此打架的地方**，而不是记住了几个名词。

如果只是把相关几讲的摘要贴给你，那就失败了——那些内容你自己也能搜到。价值全部在于**用这些工具去切你这件事**。

---

## 五个功能模块（对话协议）

技能固定走五步。你可以把它理解成五个模块，每一轮对话都会经过它们。

### 模块一：接住处境，补齐事实 ——「先别急着分析，你还缺三个数字」

**作用：** 用自己的话把你的处境重述一遍（让你确认它有没有理解错），然后问 **2–4 个会翻转结论的关键问题**。每个问题都会说明「为什么它重要」，并且尽量给选项让你直接点。

它优先补的八类事实：目标函数、硬约束、时间尺度、可逆性、可承受损失、参考类、谁出钱／谁打分、判断标准。

**你获得什么：** 一个被确认过的问题定义，以及一组「原来这个问题取决于这个」的清醒感。

**重要：默认情况下它会停下来等你的回答**，不会自问自答把话说完。只有两种情形它才会一口气分析到底——你明确说「你先按你猜的给我分析一版」，或者你一开始就把目标、约束、时间尺度、金额都讲全了。

### 模块二：匹配工具 ——「同一件事，换个视角答案就反过来」

**作用：** 从「按处境选工具」的映射表里找到最接近的几行，再从不同行各取一个，凑成 **2–4 个机制真正不同**的工具。它不会顺手堆一堆相关名词。

九个候选视角池：认知与自我 / 证据与概率 / 下注与风险 / 时间与位置 / 学习与能力 / 激励与制度 / 组织与权力 / 系统与演化 / 意义与统摄。

**你获得什么：** 知道这一轮会用哪几个工具、它们分别从哪个方向切你这件事。

### 模块三：多工具并置分析 ——「每个工具都要落到你的数字上」

**作用：** 每个工具一小节，固定三段——它怎么描述你的局面 / 它给出的判断和动作 / **它在什么情况下会失效**。

第三段是最容易被省略、也最有价值的一段：判断的边界比判断本身更值得看。

**你获得什么：** 同一件事的多个解释版本，每个都带着适用条件和失效条件。

### 模块四：综合与张力 ——「工具打架的地方，才是你这件事的真相」

**作用：** 给出五样东西——共识（哪几个工具指向同一个动作，这部分可以放心执行）、**冲突**（哪些工具结论相反，分歧来自哪个假设不同，你的哪个回答能解决它）、再想一层（你自己没意识到的更高层问题）、可检验判据（写清时间的检查点）、什么新证据会改变结论。

它内置了六组常见真实张力，遇到时会优先指出来而不是急着调和：

| 张力 | 一方 | 另一方 | 分水岭 |
|---|---|---|---|
| 集中还是分散 | 凯利公式：有 edge 就该按比例重仓 | 反脆弱：杠铃策略，先保证不毁灭 | 结果可不可重复、输了还有没有下一次 |
| 深耕还是探索 | 复利：时间越长复利越强 | 探索与利用、赛道选择：赛道错了复利也是浪费 | 赛道的收益是不是重尾、剩余游戏时间多长 |
| 该快还是该慢 | 期权：单向门三思，保留可选项 | 自我约束、认领：主动放弃自由以换取信任 | 这件事需不需要别人先信你 |
| 优化指标还是废除指标 | 激励相容：设计好的激励 | 古德哈特定律：指标一旦成为目标就失效 | 任务可不可测量、可不可多维度判断 |
| 看系统还是看个人 | 替罪羊：用系统思维取代找坏人 | 认领、授予和授权：总要有人认领后果 | 是在复盘归因还是在分配责任 |
| 追求还是放手 | 目标函数：明确你要什么 | 副产品：最珍贵的东西不能被直接追求 | 这东西是过程属性还是结果属性 |

**你获得什么：** 从「有几个道理都对」升级到「我知道它们为什么对、以及我的哪个条件决定了听谁的」。

### 模块五：回扣课程 ——「把这件事解决掉，课也顺便学了」

**作用：** 每轮收尾固定给一节，列出这一轮用到的每个工具：来自第几讲、所属板块、一句话机制、**这节课最反直觉的一点**、**最常见的误用**。

然后按需给一条延伸路径：想学进去，按什么顺序读哪几讲；只想解决眼下问题，就到此为止。

**你获得什么：** 一次对话 = 一次实战 + 两三讲真正的理解。

## 适用场景

技能内置了 40 多条「处境 → 工具组合」的直接映射，下面是最常见的八类。

### 场景 1：职业岔路口 ——「该留下还是换赛道」

**典型说法：** 干了八年的行业感觉没前途了，但不知道能去哪；或者收到一个 offer，犹豫要不要接。

**它会给什么：** 用社交资本与结构洞、赛道选择、场域、参考类预测四个视角，分别看你的**位置**（不只看能力）、你的**游戏规则**、以及同类人的**基准线**。这一类问题它一定会先问你「同类背景的人做这个选择，结果分布如何」。

### 场景 2：一个决定拿不准 ——「该不该下注、下多大」

**典型说法：** 要不要 all in 做这件事？要不要卖房创业？要不要把积蓄投进去？

**它会给什么：** 把问题从「跳还是不跳」改写成「怎么下注」。核心是凯利公式（你有没有 edge）+ 非遍历性（会不会撞上吸收壁）+ 反脆弱（输了还有没有下一次）。这三个工具经常互相拽，张力会明说。

### 场景 3：中年方向感 ——「找不到兴趣点，也不知道该做什么事业」

**典型说法：** 人到中年，钱够花但没劲，想找个真正感兴趣的方向。

**它会给什么：** 这一类它会先反着来——**兴趣和热爱是过程属性，越直接追求越得不到**（副产品一讲）。然后用临近可能（看你手上已有的零件能组合出什么）、探索与利用（你还剩多少游戏时间、37% 采样原则）、共鸣（你最近一次被什么触动并回应了它）来找线索。它大概率不会让你「先想清楚再行动」，而是让你先做出一个能留下构件的作品。

### 场景 4：组织与团队难题 ——「制度不管用、团队出不了活」

**典型说法：** 新 KPI 一上来大家就开始刷数据；团队全是能人却协作不起来；公司不知不觉在变差。

**它会给什么：** 古德哈特定律（指标为什么会变形）+ 激励相容（怎么设计才不指望人「畏威怀德」）+ 组织资本（能力长在人与人之间，不在个人身上）+ 基线漂移（评价世界的尺子跟着变差）。这类问题它常会问一句「老板是有权不改，还是没权改」——因为这决定了该修机制还是该换位置。

### 场景 5：学习与教育 ——「学了很多不会用」「孩子怎么教」

**典型说法：** 读了很多书遇到真问题还是不会决策；孩子学习没动力；要不要辞职读研。

**它会给什么：** 认知负荷理论、ICAP 框架、刻意练习、默会知识、可取的困难、知识迁移这一整段（045–056），以及教育信号、自主支持。关于孩子的问题它会特别关注「你是在赋能还是失能」。

### 场景 6：赚钱与商业模式 ——「凭什么是我赚钱」

**典型说法：** 想做点生意但不知道做什么；有个技能不知道能不能变现；要不要追这个风口。

**它会给什么：** 经济租（价值创造 ≠ 价值捕获）、阿尔法（凭什么是你）、效果推理（不知道该干什么的时候该干什么）、沃德利地图（哪些自己做、哪些外包）、机会窗口（怎么判断来早了还是来晚了）。

### 场景 7：社会与规则 ——「规则总在变，不敢做长期投入」

**典型说法：** 政策反复，不敢投长期项目；所有人都抱怨但没人能改；平台说变就变。

**它会给什么：** 慢变量（政府／平台的使命是维护稳定预期）、软预算约束（有人兜底责任就变形）、外部性、摩洛克（东亚为什么这么卷）、第三物（合作不必先有共识）。

### 场景 8：意义与人生统摄 ——「什么最值得追求」

**典型说法：** 钱够花了但每天醒来不知道为什么要起床；越想幸福越不幸福；想有个更大的图景。

**它会给什么：** 目标函数（宇宙不给奖励函数，只画悬崖）、副产品（最珍贵的不能被直接追求）、共鸣、自我约束（有限制才有力量）、探索和生发（一种人生意义）。这一类它**不会给建议清单**，而是先用工具把提问方式本身修正过来。

## 预设问题库

以下问题**只含问题不含答案**，直接复制粘贴即可。技能会自动激活。

### 入口问题（任何场景都可以从这里开始）

```
用万维钢的思维工具帮我分析一个问题：[把你的处境讲出来]。
我目前的目标是[……]，现实约束是[……]，时间尺度是[……]。
```

```
我最近在纠结一件事：[……]。先别给建议，你先把关键事实问清楚。
```

### 场景 1：职业岔路口

```
我在这家公司干了六年，做到了小组长，最近特别想出去自己做，但是又怕。你帮我看看。
```

```

```

```

```

## 深度追问：答案太浅时怎么逼它

技能是按「追问 → 并置 → 张力 → 判据」设计的，如果某一步偷懒了，用下面这几句逼回来。

**觉得它问得太碎、绕圈子：**
```
跳过提问，直接按你最可能的假设给我一版分析，并标明假设是什么。
```

**觉得它工具堆太多、没重点：**
```
只保留你觉得最关键的两个工具，其他砍掉。并告诉我为什么这两个。
```

**觉得它没有观点、两头都说：**
```
这几个工具的结论哪里是矛盾的？不要调和，直接告诉我分水岭在哪。
```

**觉得它说得对但没法执行：**
```
给我一个可检验的判据：三个月后我用什么标准判断这件事做对了？什么新证据会让你改变结论？
```

**觉得它没落到课程上：**
```
这一轮用到的每个工具，分别来自第几讲？每讲讲的最反直觉的一点是什么？最常见的误用是什么？
```

**想确认它没编造：**
```
这个工具在第几讲？把该讲的「权威来源」和「怎么用」两段原文给我看。
```

## 它的边界（必读）

**一、缺 8 讲。** 知识库覆盖 116 个讲次条目 / 114 个不同讲号，但以下 8 讲**没有被收录**：**090、091、092、100、101、102、112、117**。其中 117《立题：怎样给事情做主》在原课程文件夹里只有一个 0 字节的未完成下载文件。需要用到时它会明说「这一讲没被收录」，并用相邻讲次推理——**如果它装作知道这八讲的内容，那是幻觉，请直接质问它**。

**二、它是浓缩卡，不是全文。** 116 个单讲文件是五段式知识卡（解决的问题 / 核心概念 / 关键洞察 / 权威来源 / 怎么用），从课程正文逐讲提取，概念定义和权威出处可靠，但**不是讲次全文**。要核对作者原始表述，以每讲的「权威来源」与「怎么用」两段为准。

**三、它不是心理治疗。** 涉及持续的情绪困扰、抑郁或危机时，它会把认知解耦、安全感这类工具作为理解框架给出，并建议你寻求专业帮助。

**四、它的立场是"不打鸡血"。** 这门课的立场是「先尊重硬约束」和「不做什么往往比做什么更高级」。当你的想法撞上硬约束时它会直说——但会帮你把约束找出来，而不是简单否定你。

**改内容怎么下手：**

| 想改什么 | 改哪里 |
|---|---|
| 对话流程、底线、工具选择规则 | `SKILL.md` |
| 某个处境该用哪些工具 | `references/tools-index.md` 第 2 节的映射表 |
| 某一讲的知识点 | `references/lectures/NNN-*.md`，然后同步进对应模块文件 |
| 术语定义 | `references/glossary.md` |
| 示范节奏 | `references/dialogue-examples.md` |

改完记得重新打包（`.skill` 是个 zip）：

