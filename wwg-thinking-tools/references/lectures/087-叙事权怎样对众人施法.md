# 087　叙事权：怎样对众人施法

- **解决的问题**：领导者怎样把自己的判断变成一千个人自发的集体行动，而不是靠命令和奖金推着走？
- **核心概念**：叙事权：用定题（议程设置）、定义（框架塑造）、定我（身份认同）三个心法，把私人信念变成组织的共同知识。
- **关键洞察**：
  1. 命令只能让一个人做一件事，叙事却能让一千个人自己补完那一千条没有下达的命令。
  2. 定题不给答案只抢上游：媒体左右不了你「怎么想」却能左右你「想什么」，接受问题就进了你的场域。
  3. 框架不是换说法而是换因果模型：GPU 叫「数据中心」是成本，黄仁勋叫「AI 工厂」就成了生产资料。
  4. 超信念是让未来的幽灵闯进现在：虚构经文化反馈回路使自身现实化，先按那个未来行动，预言就自我实现。
- **权威来源**：麦库姆斯与肖 1972、恩特曼 1993、亚当斯《重构你的大脑》、尼克·兰德超信念、默顿、赫拉利。
- **怎么用**：
  1. 定题句式：「过去我们一直在争论 A。可世界已变成 B。所以真正的问题不再是 A，而是 C。」
  2. 定义句式：「这不是 X，而是 Y。所以衡量它不该看 A，而该看 B；要做的第一件事不是 C，而是 D。」
  3. 定我句式：「我们不是 X，我们是 Y」，把身份说成他们本来就有的，而不是上台喊口号动员。
