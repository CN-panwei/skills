# 018　认知解耦：三步调节负面情绪

- **解决的问题**：别人一句话就动怒、白天受挫深夜反复回放，压抑无效、伪装更累，需要能主动调节情绪。
- **核心概念**：认知解耦：把「心中的叙事」和「眼前的事实」拆开，三步——认知解离、调用视角、认知重评，合起来是一套「接化发」。
- **关键洞察**：情绪由你的感知触发而不是真相触发（巴瑞特：情绪是你对世界的构建）；解离不是消灭想法，而是从「陷入想法」变成「看着想法」。第二步最好的办法不是空想换位，而是直接问对方「你到底在担心什么」，很多冲突纯粹是误会。重评是在不篡改事实的前提下改写意义，要指向建设性行动，否则就滑向阿 Q 精神。
- **权威来源**：斯坦诺维奇《理性与反思性心智》；巴瑞特《情绪是如何产生的》；莫泽关于第三人称自我对话的研究；格罗斯情绪调节研究；哈佛《Break the Cycle》关于反刍伤身。
- **怎么用**：情绪上来先做解离——「我注意到此人正在产生一个想法」，并用第三人称自问「十分钟、十个月、十年后还重要吗」；主动切到对方、旁观者视角；再重评：「威胁→挑战」「针对我→因为情境」「挖掘负面情绪的正面意义」。
