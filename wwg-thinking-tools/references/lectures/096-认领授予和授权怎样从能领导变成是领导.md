# 096　认领、授予和授权：怎样从“能领导”变成“是领导”

- **解决的问题**：学了这么多领导力、心里也有蓝图，可是没人让我当领导，我该怎么获得权力？
- **核心概念**：领导身份建构：权力由你和人群互动共建，需要三张签名——认领（自己签）、授予（同事签）、授权（组织签）。
- **关键洞察**：
  1. 不是有能力就应该当领导：希克斯说伯恩斯缺的不是本事而是可信度，她必须「创造追随」。
  2. 最好的个人贡献者未必是最好的领导者：38843 名销售员的数据显示，销冠晋升后的团队增值与晋升前业绩负相关。
  3. 别做组织的免费保姆：张罗聚餐、写纪要、答疑、填表这类低晋升性任务，干得再多也难换晋升。
  4. 提促进性建言（给方案）能提升地位，提抑制性建言（指出风险）没有这个效果；要让人想到出路而非麻烦。
- **权威来源**：德鲁与阿什福德 2010、本森等 2019、巴布科克等 2017、菲佛《权力七规则》、《史记·高祖本纪》。
- **怎么用**：
  1. 只认领影响关键结果、横跨部门、需要判断取舍、最后拿得出看得见成果的事，先认领后果而非任务。
  2. 走声望路线而非支配路线，多提促进性建言，用能力与贡献换来别人自愿的追随。
  3. 主动扩大自己「值得被托付的半径」，拿到第三张签名后，记得为下属签下他等的那一张。
