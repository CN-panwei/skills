# 089　人身依附和角色责任：从前现代到现代管理

- **解决的问题**：为什么「懂事」「表态」「任人唯亲」这一套至今仍在运行，它凭什么存在、又为什么不高级？
- **核心概念**：前现代管理的灵魂是人身依附，靠恩、威、亲、表，规矩长在具体的人身上；现代管理讲究角色责任，人对角色负责。
- **关键洞察**：
  1. 前现代管理只要想做大就陷入悖论：它拼命寻找忠诚，最后奖励的却是最会表演忠诚的人。
  2. 它的上限是邓巴数：人脑能稳定维持的熟人关系约一百五十人，中层于是成了信息关口，报喜不报忧。
  3. 病根不是权力太强而是权力太弱；被恐惧压住的组织很安静，但安静不等于秩序，很多时候只是失明。
  4. 混乱有时是一种利益结构：越说不清楚，靠模糊授权和揣摩上意的人越有空间，现代管理会让权力变透明。
- **权威来源**：马基雅维利《君主论》、西塞罗书信、韦伯家产制、邓巴数、戴明、诺斯 1993、布卢姆与范里南、梅因。
- **怎么用**：
  1. 把组织从「一串私人关系」改造成「一组可替换的角色接口」：职位定权限、流程传信息、指标反馈结果。
  2. 用会计、审计、绩效评价和申诉机制把信任从具体的人身上移到制度上，让人可以流动而角色还在。
  3. 记住权责清晰不是束缚而是解放：权力有限，责任才有限，清楚自己能决定什么才敢放开手脚干。
