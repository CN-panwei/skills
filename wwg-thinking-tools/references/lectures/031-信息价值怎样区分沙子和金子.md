# 031　信息价值：怎样区分沙子和金子

- **解决的问题**：刷手机、追大 V、听硬核播客、订阅 AI 服务，被 FOMO 驱动，接收了大量信息却越来越惶惶不可终日。
- **核心概念**：**信息价值（VOI）**对价值的定义极严格：只有当一条信息能改变你的实际行动时它才有价值。VOI＝有这条信息时你能做出的最佳选择比没它时平均多赚多少。配套 **EVPI**（完全信息期望价值）与 **EVSI**（样本信息期望价值）。
- **关键洞察**：
  - 石油公司算例：不打井期望收益为 0，有勘测报告时期望价值 20%×4000 万＝800 万美元。
  - 高价值信息三特点：目标导向、带有痛感（改变先验）、出现在决策边界上。
  - 信息焦虑不是因为缺信息，而是因为决策没有落地——整天消费信息却不做实质决策就是「漂流」。
  - 高 VOI 信息往往细碎、不耀眼、有点无聊，最重要的是你自己的数据。
- **权威来源**：Ronald Howard 1966《Information Value Theory》；Raiffa & Schlaifer 1961（EVPI/EVSI）；Polymarket 博士生套利案例；信息觅食理论。
- **怎么用**：① 先想清楚要做什么决定、这条信息能否改变决定，再看成本；② 用高成本手段换高 VOI（请师傅验车、A/B 测试、MVP）；③ 把注意力从宏观叙事转向约束、反馈和因果关系。
