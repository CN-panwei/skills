# 050　综合调研：在没有教科书的地方挖掘真知

- **解决的问题**：教科书上没有、别人也说不清的真知从哪来？怎样把零散公开材料变成能指导下注的判断。
- **核心概念**：**综合调研（Synthesis）**：自己立题、自己找材料、自己判断可信度，回答「所以呢」并写成报告；分定位式、结构化、生成式三级。
- **关键洞察**：
  - 搜索只告诉你有什么，总结是把东西说短，分析是拆开，综合调研是把拆开的东西重组成新整体。
  - 真相常常不在任何一份材料里，而在材料之间：斯诺把死亡名单、地图和水泵位置叠在一起发现了霍乱水源。
  - 主流学者的共识其实远大于分歧，真正的分歧很微妙，那微妙之处才最值得说话。
  - 写作不是思考之后的包装，写作即思考；不写下来分不清自己是真懂还是假懂。
- **权威来源**：约翰·斯诺霍乱调查与约翰逊《幽灵地图》；文献综述作为研究方法（斯奈德）；科克伦证据综合。
- **怎么用**：① 初级：把问题压成一句真问题，分清共识、争议与误区，压成两分钟能讲清的话；② 中级：读遍该领域主流作者，弄清门派与争论卡在哪，能把反对那派总结得让他们自己也认可；③ 高级：把各方证据摆在一起拼图，看出更大的故事和缺失的那几块拼图。
