# 011　问答：为什么承认“原来我是错的”那么难？

（答疑：《约束》《可能》《内核》《能耐寻求定理》《供给侧心态》等一讲合集）
- **解决的问题**：成年人被指出错误时不但不改反而更顽固，读者问如何破局、又如何看待探索与自我更新。
- **核心概念**：逆火效应——指出错误会让对方更坚定；根因是观念与身份认同、社会归属、自我叙事绑在一起，质疑观念等于质疑他的存在合理性。
- **关键洞察**：改观念要先把它和身份解离：「你就算信西医也不等于不爱国」；关键是让他理解旧观念的形成可以谅解、他这个人仍然可爱。日省日志改不了内核，要靠对「苗头」做反向动作训练。增加可能性相当于买期权，而期权有到期时间，该行权就得行权。体制内的目标函数必须先想清楚是做大还是自保，两者代价完全不同。
- **权威来源**：逆火效应；凯利公式（后讲）；马斯洛「向前一步求发展，或者后退一步求安全」；科尔维《高效能人士的七个习惯》刺激与回应之间的空间。
- **怎么用**：把旧观念从「我错了」重述为「当时有用、现在可以多一个工具」；发现自己第一反应模式后，在苗头再出现时做反向动作；用最小胜利打破习得性无助。
