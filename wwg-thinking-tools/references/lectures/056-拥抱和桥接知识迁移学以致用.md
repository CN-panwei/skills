# 056　拥抱和桥接：知识迁移，学以致用

- **解决的问题**：为什么读了那么多书还是不会用？知识怎样才能从考场迁移到真实工作和生活场景。
- **核心概念**：**拥抱与桥接**（珀金斯与所罗门）：拥抱是让教学贴近未来应用情境（低路迁移），桥接是抽取图式和心智模型再类比到别处（高路迁移）。
- **关键洞察**：
  - 从学到用有三道锁：表征锁（只学到碎片）、触发锁（现实中无线索唤醒知识）、生态锁（无反馈而退回旧习惯）。
  - 大脑检索高度依赖情境：你把公式存进了「物理课与考试」文件夹，街上的力学问题不会自动去扫描它。
  - 新手按表面特征分类（斜面题、滑轮题），高手按深层原理分类（能量守恒、牛顿第二定律）。
  - 把两个不同场景的案例放在一起直接对比，能让迁移率提升两倍；模仿是新手创造力的前提。
- **权威来源**：怀特海「惰性知识」(1929)；珀金斯与所罗门 1988；金茨希文本基底与情景模型；奇等专家新手分类研究；洛温斯坦类比编码实验。
- **怎么用**：① 学技能就找一个真实会议、真实互动甚至真实冲突做小范围演练；② 读完书做向前桥接：它解释了什么结构？未来最可能在哪三个情境用？第一步动作是什么？③ 事后写比较笔记：表面哪里不同、深层哪里相同，下次看到什么信号就调用。
