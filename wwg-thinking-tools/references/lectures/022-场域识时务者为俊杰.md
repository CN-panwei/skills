# 022　场域：识时务者为俊杰

- **解决的问题**：自认优秀却上上下下都不待见，感觉到处是潜规则，不知道为何努力不被承认。
- **核心概念**：布迪厄场域理论：场域是由不同位置构成的关系网络，有自己的规则、筹码和裁判；关键概念为场域、Doxa（不言自明的信念）、惯习、资本，最高阶是象征资本。
- **关键洞察**：你能不能被承认，取决于是否符合这个场域对「好」的定义；努力不是硬通货，合规才是。你以为的不公平，往往是你不理解赛场的计分规则。学术界是「反向市场」：越通俗畅销越被怀疑不够严肃，萨根因此落选美国国家科学院院士（萨根效应）。象征资本决定名誉与权威，能定义其他资本的正当性，并伴随象征暴力——听不懂内部梗的人会主动改造惯习去迎合。
- **权威来源**：布迪厄与华康德《实践与反思》；布迪厄《学术人》；象征资本论文；「到什么山上唱什么歌」；卡尔·萨根院士落选典故。
- **怎么用**：按四步攻略场域——摸清位置关系与大小王、识别 Doxa、检查自己惯习是否兼容、积累场域看重的资本；三条路选一：按规则玩、换场域、先拿到象征资本再改变规则；抱怨是最没用的一条路。
