# 020　安全感：人需要有所依靠

- **解决的问题**：明明想上进却总是惊慌紧绷、讨好或冷漠，缺的是底气——人为什么需要有所依靠才敢往外闯。
- **核心概念**：安全感作为看人的一个维度；依恋理论：焦虑型、回避型、安全型（约 65%–70%），来源是关系提供的安全基地与安全港湾两个功能。
- **关键洞察**：我们的本能是寻求依靠而不是寻求独立，有依靠才有安全感；一岁左右的依恋类型会预示七岁时的受欢迎程度与未来婚恋关系。缺乏安全感会外显为囤积、炫耀、过度讨好或冷漠、盯着评价、不能容错；有安全感的人才敢进入拓展-构建状态。安全感可以习得：觉察依恋类型、自我关怀、自建可控小环境，再去找基地与港湾；给别人当基地和港湾会让你从索取者变成供给者。
- **权威来源**：安斯沃斯陌生情境实验；鲍尔比「生活最好被组织成一系列从安全基地出发的冒险」；弗雷德里克森拓展-构建理论；马斯洛需求层次；Google 亚里士多德计划；埃德蒙森心理安全定义。
- **怎么用**：想夺命连环 call 或想冷暴力逃跑时先暂停，告诉自己「这是我的旧程序在运行」；像对好朋友那样对自己，整理房间、规律作息，先建最小港湾；对他人先接住情绪、不急着讲道理，并确保支持一致可预期。
