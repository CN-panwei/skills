# 080　替罪羊：从「找坏人」到「看系统」

- **解决的问题**：出事后到底该抓坏人还是看系统？为什么一群正常人在理性行事之下把系统搞崩溃了。
- **核心概念**：用**系统思维**取代「戏曲思维」；安全工程区分「**人因视角**」（盯一线人员的疏忽懒惰违规）与「**系统视角**」（问防线为什么失效），并区分「**显性失误**」与「**潜在条件**」。
- **关键洞察**：
  - 米尔斯：一个人失业是个人困扰，一千五百万人失业是公共议题。
  - 瑞森「瑞士奶酪模型」：重大事故很少是单一原因，而是多道防线的洞刚好排成一条直线；最该整改的是潜在条件。
  - 波音 737 MAX 是四层洞排成直线（MCAS 软件、训练淡化、赶超空客的竞争压力、FAA 委托认证）；2021 年得州寒潮中天然气机组占故障机组 58%。
  - 吉拉尔的替罪羊机制：人群为了从「所有人斗所有人」走出来，转为「所有人斗一个人」；最热衷维护替罪羊解释的恰是最弱势的群体。
- **权威来源**：米尔斯《社会学的想象力》；马克思《路易·波拿巴的雾月十八日》；李·罗斯「基本归因谬误」；瑞森《人因错误》；美国众议院 737 MAX 最终报告；FERC/NERC 得州停电报告；吉拉尔《暴力与神圣》《替罪羊》；戴维·马克思「公正文化算法」三分法。
- **怎么用**：① 用三分法追责：无心之失安慰并修系统、冒险行为纠正训练并消除错误激励、鲁莽违规严厉追责；② 事故复盘先问「为什么这么多环节没有一个把风险拦住」；③ 只处理人不处理条件，下一次还会得到同样的事故。
