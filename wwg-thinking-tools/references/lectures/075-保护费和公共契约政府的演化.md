# 075　保护费和公共契约：政府的演化

- **解决的问题**：政府从哪来？为什么说政府本质是拥有最终强制权的组织。
- **核心概念**：奥尔森「**流动强盗→定居强盗**」演化：强盗学会长期主义就变成统治者，把保护费改造成税收、把统治者改造成代理人、把臣民改造成公民。
- **关键洞察**：
  - 政府与公司、平台、学校的区别不在服务更好或更仁慈，而在它拥有最终强制权；韦伯定义国家＝在疆域内成功主张合法物理暴力垄断的人类共同体。
  - 国家是战争制造出来的：「战争制造国家，国家制造战争」；斯科特指出谷物是理想征税对象，种谷物的农民被绑定在土地上，故农业核心区都走向大一统帝国。
  - 前现代国家是「家产制」，老百姓被视为汲取的资源；皇帝也是高危职业——中国 611 位皇帝非正常死亡率 44%，平均寿命 39.2 岁。
  - **黄宗羲定律**：轻徭薄赋→官僚扩张→加税→并税改革→再发明杂税，「积累莫返之害」。
  - 现代国家三个节点是大宪章、光荣革命、美国制宪；「限制权力不是写在纸上，而是写在权力分布里」。
- **权威来源**：奥尔森论独裁、民主与发展；格雷伯与温格罗《人类新史》；霍布斯《利维坦》；韦伯《以政治为业》；蒂利《作为有组织的犯罪的战争制造和国家制造》；斯科特《作茧自缚》；张宏杰论皇帝寿命；秦晖「黄宗羲定律」。
- **怎么用**：① 评价治理时把问题从「这个人好不好」改成「我们这个制度行不行」；② 用「把隐蔽的自由裁量锁进制度的笼子」的思路看问题；③ 作为读书人，把质疑政府视为本分而非「找麻烦」。
