# 098　对称性破缺：命运不过是冷却了的偶然

- **解决的问题**：随机的小差异为何会凝固成坚不可摧、无法更改的既成事实。
- **核心概念**：**对称性破缺**＝从「什么都可能」变成「只有一种可能且坚不可摧」。利用它三心法：观察可塑性、寻找序参量、寻求可固化性。早期宇宙密度涨落只有十万分之一，却冷却成了星系的位置。
- **关键洞察**：① 破缺不是瑕疵而是世界的生成机制：完美对称意味着什么都没有；② 可塑性不是权力的函数而是温度的函数，窗口是「将冷未冷」；③ 命名→样板→公开→固化。
- **权威来源**：安德森《多者异也》(1972)；古斯暴胀理论(1981)；萨哈罗夫；阿瑟（路径依赖）；舍弗尔等临界转变预警(Nature 2009)；拉德克利夫分治线、李斯书同文、华盛顿两届惯例。
- **怎么用**：① 进入新领域先问：这里是否还有三四种说法都讲得通、技术路线未定型（＝热）；② 找序参量（如两条路线采用比例的差）；③ 小动作必须被系统记住：写进日程、模板、合同、手册。
