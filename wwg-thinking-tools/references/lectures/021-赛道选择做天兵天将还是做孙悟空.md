# 021　赛道选择：做天兵天将，还是做孙悟空？

- **解决的问题**：每一步都走对、赢过很多人，最后却只是别人故事里的编号；想知道该待在体制内还是体制外。
- **核心概念**：赛道选择（Game Selection）：先选玩什么游戏再谈最优策略；体制内（适应别人建立的秩序）与体制外（直面真实世界、自负风险）是两种游戏。
- **关键洞察**：体制内钻研人际关系逻辑、地位来自被分配，代价是可替代性、把指标当目的（古德哈特定律）与规则突变的系统性风险；体制外研究物理世界逻辑、地位靠自己创造。最危险的是错配：用天兵心智在重尾赛道求稳，或用悟空的性格在科层体系里求自由。悟空赛道的两个战略能力：利基构建（不找生态位而是构建生态位）与效应化（打开冰箱看有什么菜做什么饭，做你能做而非该做的事）。天兵也应当有秘密项目，悄悄修一个花果山副本。
- **权威来源**：政治技巧与职业成功、可晋升性的元分析研究；利基构建的生物学研究；萨拉斯瓦蒂 2001 年效应化理论；创新最容易起源于边缘地带。
- **怎么用**：用三道自测题辨别（焦虑绩效晋升还是长期能力曲线、怕被淘汰还是怕停止升级、想成为职称还是功能）；体制内把指标当工具，管理预期、竞标解释权；体制外练不对称技能，靠作品和用户积累不需要批准的影响力。
