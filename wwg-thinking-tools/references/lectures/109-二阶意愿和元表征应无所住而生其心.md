# 109　二阶意愿和元表征：应无所住，而生其心

- **解决的问题**：外界没有规定你该怎么活，那自由是什么、该怎样做出选择。
- **核心概念**：**二阶意愿**＝我让哪个欲望真正支配我的行动（是一个任命动作，不是评价）；**元表征**＝对表征关系本身的表征，即给思想加上引号、跳出你面对的那个问题。
- **关键洞察**：① 真正的自由不是随心所欲，而是有能力决定什么才算「我的心」；② 训练动作只有三个：察觉（把「我想刷手机」改成「我心里出现了一个想刷手机的欲望」）、重编（奖励只是信号不是命令）、布置（主动设置自己的训练环境）；③ 没有「真我」可挖——成长就是让曾经的主体变成客体（凯根），但更要「生其心」，不设目标本身就是一种「有所住」。
- **权威来源**：法兰克福(1971)；亨登(2008)；沃森(1975)；派利夏恩(1978)；普鲁斯特开放式递归性(2007)；凯根；庄子《逍遥游》；《金刚经》；另引扎哈维《大语言模型不能跳》(2026)。
- **怎么用**：① 核心动作只有一个：把正在充当主体的东西（欲望、情绪、框架、叙事）变成你眼前的客体；② 顺着行动层→目标层→问题层→叙事层→身份层→价值层逐层追问，从解题走到换题再到换我；③ 目标函数必须是你定的、审查权在你手里，它可以评判这件事却不能定义你是什么人。
