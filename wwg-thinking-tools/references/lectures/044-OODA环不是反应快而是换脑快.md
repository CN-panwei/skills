# 044　OODA 环：不是反应快，而是换脑快

- **解决的问题**：急诊室推进满身是血的病人、股市突然崩盘、对手发布颠覆性产品——实战场合没时间调研，手忙脚乱是大忌，但不反应也不对。
- **核心概念**：**OODA 环**＝观察—定向—决策—行动，循环往复。精髓不是反应快而是**换脑快**：迅速判断这是什么局、什么是重点什么是噪音。博伊德后来把 D 解释成「假设」、把 A 解释成对世界进行「压力测试」。最关键的是第二个 O「**定向**」，博伊德称其为整个循环的「阵眼」。
- **关键洞察**：
  - 要点不在你的循环比对方快，而在你的循环有效，最好还能误导对方的循环。
  - 定向由四股力量塑造：遗传背景、文化传统、既往经验、正在展开的情境。
  - 外行以为高手的每个行动都为取得进展，但 OODA 提倡很多行动只是「拨弄」一下现实（打一拳看对手反应、投个 MVP 看反馈）。
  - 现代战争比的是组织级的换脑速度：赢家是学习链最短的一方。
- **权威来源**：约翰·博伊德（1987《Organic Design for Command and Control》）；中途岛海战案例；美军「决策优势」；Zara 三周新品上架；乌克兰无人机战场案例；预测加工与自由能原理的主动推断。
- **怎么用**：① 事事从定向入手（考试失利先分层、数据下滑先做最小探针、夫妻吵架先问对方眼里这是个什么事儿）；② 用主动刺探代替求定论；③ 个人健康每周跑一次 OODA 小循环。
