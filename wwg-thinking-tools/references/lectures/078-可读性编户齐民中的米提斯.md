# 078　可读性：编户齐民中的米提斯

- **解决的问题**：为什么大系统总要求整齐统一？被系统「读薄」的个人该怎么办。
- **核心概念**：**可读性（legibility）**＝国家为了让社会能被统计、征税、征兵，要求社会按自己方便的方式排列；**米提斯（mētis）**＝在不断变化、从不重复的现场里临机应变、把事情做成的活智慧。
- **关键洞察**：
  - 关键问题不是国家读社会，而是国家为了读社会反而把社会读薄；朱元璋的黄册、鱼鳞图册、世袭职业，等于要老百姓放弃人生的可变性。
  - 德国「科学林」单一种植一个世纪后整片林子死掉：被清走的真菌、昆虫、鸟雀、腐殖质正是森林的免疫系统——「国家看见的其实不是森林，而是木材」。
  - 米提斯不是能填进表格的能力，而是知道表格什么时候不够用的能力。
  - 想让人可替换的制度，最后让最不可替换的师爷掌了实权；苏联工厂靠万能修理工和「推手」活着——「他们不是体制的成就，是体制的幸存者」。
- **权威来源**：斯科特《国家的视角》《作茧自缚》；张宏杰《中国国民性演变史》；李约瑟难题；清代胥吏与绍兴师爷研究；山西票号研究；Ledeneva 论苏联 blat 关系网；莱夫与温格《情境学习》。
- **怎么用**：① 温养米提斯六步：到场、变式、复盘、结网、留痕（厚档案记关键案例与「差一点就失败」）、转译；② 把公开文本做到无可指摘换取自由空间，把判断力放在指标看不见的地方；③「入格」但不「入笼」。
