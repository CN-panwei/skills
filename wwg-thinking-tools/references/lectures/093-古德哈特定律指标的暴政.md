# 093　古德哈特定律：指标的暴政

- **解决的问题**：想搞公平合理、任人唯贤的考核，为什么一设数字指标就开始奖励最会刷指标的人？
- **核心概念**：古德哈特定律：指标本来用来观察现实，一旦变成奖惩目标，人们就转而优化指标而不再优化现实。
- **关键洞察**：
  1. 病根不是权力太强而是权力太弱：最迷信量化的是权威不足的机构，量化是「做了决定却像没人做决定」。
  2. 它反对的不是量化而是幼稚的量化：数字可以作为判断的依据之一，但不应该取代判断本身。
  3. 指标会演化、堵不住：从论文数到引用数到 h-index 再到顶刊指标，发文件禁止的作用有限。
  4. 你也会古德哈特你自己：把坐几小时当学习、把体重当健康、把秒回当爱，是自己主动交出了判断权。
- **权威来源**：古德哈特 1975、斯特拉森 1997、卢卡斯批判、坎贝尔定律、波特《对数字的信任》、莱顿宣言。
- **怎么用**：
  1. 指标只做素材不做判决书——指标是证人，不是法官，不规定「几篇等于晋升、不够就一票否决」。
  2. 用代表作评价并逼评委书面写清：他的核心贡献是什么、解决了哪个问题、反对意见是什么。
  3. 评价按角色分类，再加标准公开、利益相关者回避、落选可申诉，每隔几年反审计指标诱导出的坏行为。
