# 052　可取（以及不可取）的困难：把身心调到最适合学习的状态

- **解决的问题**：学习一定要吃苦吗？睡眠、运动、情绪这些「看不见分数」的东西到底该不该牺牲。
- **核心概念**：**可取困难**（比约克夫妇）：对学习有益的阻力，会让短期表现变差却增强长期记忆与迁移；前提是分清「表现」和「学习」。
- **关键洞察**：
  - 最有利学习成绩的睡眠时长是每天 8 小时；牺牲睡眠换成绩，即便纯功利地看也不可取。
  - 恐惧制造服从而不是理解：高压刺激打击前额叶，威胁会降低工作记忆表现。
  - 最有利于学习的情绪配方是：安全感打底 + 好奇心点火 + 适度压力提速。
  - 20 分钟中等强度急性运动能提高唤醒度、产生乳酸并刺激 BDNF，是稳定可靠的「大脑化肥」。
- **权威来源**：比约克夫妇可取困难研究；中国儿童和青少年抑郁症状检出率 26.17% 的荟萃分析（2024 年汇总 439 项研究）；上海学生睡眠研究；阿恩斯坦关于压力与前额叶的综述。
- **怎么用**：① 用提取练习、时间间隔、交错学习三种操作替代反复重读；② 学习前先动 10–20 分钟提唤醒度并点好奇心，难概念手写、深阅读用纸；③ 把睡眠写进学习计划，每天三四个小时高强度就够，写不完的作业应该抵制。
