# 028　颗粒度和因果中介：用模型思考

- **解决的问题**：没有模型就只会对结果做冲动反应——指标差就喝枸杞、项目延期就让加班、成绩下滑就打骂，即「对着自己看不懂的系统发脾气」。
- **核心概念**：**模型**是事物在头脑中的结构镜像。**好调节器定理**证明：系统的每一个好调节器都必须是该系统的一个模型。好模型有两个要求：**颗粒度恰到好处**（最小描述长度＝模型长度＋数据补丁长度最小，太细过拟合、太粗欠拟合）；**包含因果关系**（珀尔：干预之下 X 单方面变化使 Y 概率上升，才是 X→Y）。
- **关键洞察**：
  - 别盯终点，盯中介：「生气→不良生活习惯→癌症」，后者才是可干预的控制点。
  - 《点球成金》的关键中介是被忽视的「上垒」；足球的杀招是提高期望威胁的倒数第二、三脚传球。
  - 高压缩才有理解：「流动性收紧导致风险资产重估」一句话能解释八成波动。
  - 颗粒度由主观需求决定，地图不是疆域，但没地图你连路都上不了。
- **权威来源**：科南特与阿什比 1970「好调节器定理」；珀尔《为什么》（do-operator、中介变量）；最小描述长度（Grünwald）；奥卡姆剃刀；刘易斯《点球成金》；Expected Threat（Singh 2018）。
- **怎么用**：① 遇事先画变量与因果箭头，找到关键中介再动手；② 用最小描述长度准则砍变量，别什么都要日报；③ 用模型区分环节归因（是注意力、记忆编码还是提取问题）。
