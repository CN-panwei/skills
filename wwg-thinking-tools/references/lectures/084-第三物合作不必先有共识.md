# 084　第三物：合作不必先有共识

- **解决的问题**：立场、利益、价值观都不同的人，怎么不靠说服就开展有序合作。
- **核心概念**：**第三物（third object）**＝能被双方共同看见、共同操作，从而把「人对人」的直接僵局改造成「人围物」的共同局面的东西；学术前身是斯塔与格里斯默的「边界物」。
- **关键洞察**：
  - 人类不是先有共识才合作，而是先能一起盯住同一个东西才慢慢长出共识——共同注意是「你→那个东西←我」的三角关系。
  - 「共同理解是奢侈品，共同对象才是日用品」：价格是市场的第三物；《巴黎协定》的 2℃/1.5℃ 是全球气候治理的第三物。
  - 「**问题外化**」是关键机制：人一旦被定义为问题只能防御，问题一旦被外化人就可以行动；「人不是问题，问题才是问题」。
  - 谢里夫「超级目标」：一起把陷进泥里的卡车推出来才能化解敌意——「共同的敌人凝聚得快，共同的目标凝聚得久」。
- **权威来源**：Tomasello 等论共同注意；斯塔与格里斯默 1989 年边界物论文；哈耶克《知识在社会中的运用》；叙事疗法（怀特）；费希尔与尤里《谈判力》；谢里夫「超级目标」；《礼记》「乐者为同，礼者为异」。
- **怎么用**：① 想争取主动就别空着手进场，先拿出一个「球」——一页 memo、一张流程图、一份清单、一个原型；② 创造共享物（一起养花、记一本账、一次旅行、一个项目）；③ 警惕黑暗面：一旦「大家眼里只剩下它」，就会变成替罪羊、KPI 崇拜或摩洛克。
