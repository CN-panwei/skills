# 016　社交资本、结构洞和搬家：容易向上流动的位置

- **解决的问题**：同样天资与勤奋，为什么有人翻身有人一辈子原地打转——机会更多由你所在的位置决定。
- **核心概念**：三个定位工具——社交资本（切蒂三种量化指标）、结构洞（伯特：站在两个不相连网络之间做经纪人）、搬家（尽早迁往机会密集处）。
- **关键洞察**：只有经济连通性（跨阶层友谊）显著预测穷人的向上流动，社会凝聚力和公民参与几乎无效；出身贫寒但长在经济连通性高的社区，成年收入平均高 20%。接触不够，还要破交友偏差：群体越大偏差越高，小群体、稳定密集互动（宗教团体、以色列兵役）最低。结构洞的本质不是传话而是翻译，位置本身就是资本。
- **权威来源**：切蒂代际流动与 Facebook 210 亿对好友研究（2022 Nature 两篇）；伯特结构洞研究；格兰诺维特弱联系；以色列《创业的国度》；切蒂 2018 年邻里暴露效应（每多待一年变好 4%）；2025 英国 Meta 研究。
- **怎么用**：用参考类、市场前景、个人复利感三个信号判断该留该走；把关系放进共同任务（一起做项目、训练、比赛）而非寒暄；穷则搬家、越早越好，努力成为两个网络之间的结构洞。
