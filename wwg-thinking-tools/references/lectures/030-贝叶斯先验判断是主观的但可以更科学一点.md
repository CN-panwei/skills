# 030　贝叶斯先验：判断是主观的，但可以更科学一点

- **解决的问题**：面对新同事可不可靠、爆料该不该转、身体不适要不要去医院，人迫切想要正确答案，而所有决策都必然带主观成分。
- **核心概念**：**贝叶斯主义**——概率是信念的度量，是对你无知程度的量化；**先验**是成见，是可量化、可更新、可审计的认知起点。公式含义即「后验＝先验×证据修正」，取对数后更直观：后验＝先验＋证据更新。
- **关键洞察**：
  - 罕见病例子：发病率 0.1%、检测准确率 99%，后验仍只有 1/11——证据再强，先验极低时后验仍不高。
  - 两种典型错误：完全没有先验（听风就是雨）和先验不可动摇（把概率设成 0 或 1）。
  - **克伦威尔法则**：可以设成 99.999%，但不要设成 1，给自己留「我可能错了」的空间。
  - 大脑是主动预测的贝叶斯推理机：证据与先验不符时必须做点什么。
- **权威来源**：托马斯·贝叶斯（1740 年代）；克伦威尔 1650 年致苏格兰教会的信；凯恩斯「当事实改变时，我改变我的想法」；垃圾邮件过滤的贝叶斯算法；自由能原理。
- **怎么用**：① 用已知频率、科学知识作先验起点，再把个人具体情况当证据逐项更新；② 判断新人时先按环境设先验，再通过办一两件具体事更新；③ 证据与先验冲突时，或更新推断，或主动改变环境。
