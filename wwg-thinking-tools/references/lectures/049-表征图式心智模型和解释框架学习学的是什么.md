# 049　表征、图式、心智模型和解释框架：学习学的是什么

- **解决的问题**：读了很多书、笔记记得密密麻麻，遇到真问题仍不会决策——学习到底该学什么。
- **核心概念**：学习四层级——**表征**（概念、变量、关系）、**图式**（打包好的模式识别模板）、**心智模型**（能推演因果与反馈的会动的图式）、**解释框架**（对一整个领域的系统性看法）。
- **关键洞察**：
  - 学习即压缩：信息是授人以鱼，知识是授人以渔；讲规律的书比讲故事的书杠杆高得多。
  - 图式让你能脑补：巴特莱特实验中英国人回忆印第安神话时不自觉改成了英国逻辑。
  - 掌握心智模型的标准，是它会在关键时刻自动跳出来、可迁移，而不只是你会说的名词。
  - 「解释框架」是作者自造词，约相当于小号的范式，可以只是一家之言。
- **权威来源**：提斯比信息瓶颈理论；巴特莱特《记忆》(1932)；皮亚杰；克雷克《解释的本质》(1943)；费曼积分号下求导；芒格心智模型清单。
- **怎么用**：① 读书不再问「这篇讲了什么」，而问能拿走哪些表征、图式、心智模型和解释框架；② 接触新领域先提取核心概念与关键变量，动手画成关系图；③ 学到一个模型就追问它的变量、输入输出、机制链条、反馈延迟和失效边界。
