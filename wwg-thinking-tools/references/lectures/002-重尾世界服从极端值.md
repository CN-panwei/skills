# 002　重尾：世界服从极端值

- **解决的问题**：我们从小生活在「平均化」的小世界里，体感是差别不该太大、平均才是正义，这与世界的真实面貌有重大差异。
- **核心概念**：
  - **重尾分布／肥尾**：极端少数占据特别大份额，数学上最典型是幂律；与身高那种短尾正态分布相对。
  - **80/20 法则**：比例可能是 10:90 甚至 1:99，关键是极端少数占大份额。
  - **正反馈／马太效应**：越大越容易更大，是重尾的共同成因。
  - **乘法世界 vs 加法世界**：乘法世界的增量 = 当前动作 × 存量（有复利）；加法世界一天劳动换一天报酬。
  - **吉布拉特定律**：公司增长率与规模近似无关，所以体量差距必然越拉越大。
- **关键洞察**：
  - 对重尾谈平均值没有意义：高考这种相加赛道要补短板，乘法世界只需一块很长很长的长板。
  - 做乘法不只对富人有利，强强联手是多赢（请明星是因为她最能放大你的产品）。
  - 贫富差距没那么可怕：没有永远的富人，纵看一生多数贫困者收入会显著提高；「有人飞得高不可怕，整个气流停了才可怕」。
- **权威来源**：帕累托；吉布拉特定律；索维尔《社会正义谬误》；奥特曼；洛特卡 1926；Angel Returns 2016（约 10% 的投资退出贡献 85% 现金回报）；塔勒布「黑天鹅」。
- **怎么用**：① 判断自己处在加法还是乘法赛道；② 主动与资本、网络效应、声望连接，建立个人品牌与复利；③ 像风投一样非平均地下注，并对赢家追加投资。
