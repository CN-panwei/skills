# 094　流程、清单和经验库：把聪明外置成系统

- **解决的问题**：公司除了「人」和「制度」，还需要什么才能真正成为一台高效做事的机器？
- **核心概念**：智件：长在组织身上的聪明，沉淀方法（技能）、标准（护栏）和经验（记忆）；制度保证组织不乱，智件保证组织不笨。
- **关键洞察**：
  1. 企业大到一定程度，个人的聪明必须被翻译成技能，否则聪明会被规模吞噬；小团队靠默契，大组织靠接口。
  2. 错误往往不来自无知，而来自疲劳、打断、赶时间和「我以为你查过了」；清单提供的是认知卸载。
  3. 最佳实践有内部黏性：同一家公司内部一个团队的好做法搬到另一个团队都经常失灵，别犯器官移植病。
  4. 组织有三重境界：人治组织、流程组织、学习型组织；流程一旦神圣化就僵化，绕开流程应是信号而非违规。
- **权威来源**：纳尔逊与温特、任正非 IPD「先僵化后优化再固化」、WHO 手术安全清单、苏兰斯基、航天归零。
- **怎么用**：
  1. 给核心业务一条稳定技能、给每个不可逆节点一道护栏、给每一次成败一份记忆。
  2. 让好打法走完一生：小范围实验、按机制前提边界写入记忆、固化成 SOP、立清单护栏、每单结果回写。
  3. 用三个症状自查：一休假公司就停摆是技能没写出来，总在事后赔钱补救是缺护栏，新人重踩老坑是没有记忆。
