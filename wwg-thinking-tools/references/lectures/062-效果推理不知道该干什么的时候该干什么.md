# 062　效果推理：不知道该干什么的时候该干什么

- **解决的问题**：有野心、有时间、有点资源，却不知道该干什么；是不是非得先想清楚方向才配开始行动。
- **核心概念**：**效果推理**（萨拉斯瓦蒂）：手段已知、创造目标——先用手里已有的东西，干出一个会改变下一步的小结果；与目标已知、选择手段的因果推理相对。
- **关键洞察**：
  - 创业专家多用效果推理，MBA 新手倾向因果推理；80 页商业计划书预测五年收入曲线跟算命差不多。
  - 创新度越高的项目，效果推理与绩效越正相关；目标清晰、市场稳定后应切换回因果推理。
  - 五原则：手中之鸟、可承受损失、疯狂拼布、柠檬水、驾驶舱里的飞行员，连起来是一个创业版 OODA 环。
  - 效果推理不说「相信自己」而说「盘点自己」，不说「坚持到底」而说「先做一小步」。
- **权威来源**：萨拉斯瓦蒂 2001 年论文与《效果推理》专著；专家与新手决策实验(2009)；U-Haul 创业案例；布雷特尔等企业内部研发研究。
- **怎么用**：① 先回答三个问题：我是谁、我会什么、我认识谁（谁愿意真投入）；② 只问可承受损失；③ 带着粗糙想法去换真实承诺（试用、介绍客户、订金、开放渠道），把意外当成新的入场券。
