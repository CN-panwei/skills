# 017　问答：为什么喜欢的事却难以启动？

（答疑：《复利》《自我决定理论》《自由能原理》《主动高认知负荷》《WOOP》诸讲）
- **解决的问题**：明明喜欢写小说却启动困难；换岗位后旧积累是否作废；错过复利窗口期还来得及吗。
- **核心概念**：吸血鬼悖论——没成为吸血鬼就不知道做吸血鬼的感受；只有先做起来，感受和判断才可能出现，一边行动一边内化。
- **关键洞察**：换岗位旧积累不会浪费，复杂迂回的经历不是沉没成本而是资本，高管 CEO 多是换过多岗甚至多行业的人。人生不是只有一局而是很多局，新技术新局面的出现就是重开一局。积累不等于追赶，补偿性的激进投入反而透支健康，有些窗口期过了要认命。写小说的多半爱的是拥有作品的人设，真爱的人早就在写了。
- **权威来源**：《范围》《成为黑马》相关研究；《大西洋月刊》2026 年批评零内省；马斯克、蒂尔、安德森自称「零内省」。
- **怎么用**：想得太多做得太少，宁可动作快一点、内省少一点；为探索设一个交稿截止日期；错过就盘点手里的牌，等下一局新游戏再入局。
