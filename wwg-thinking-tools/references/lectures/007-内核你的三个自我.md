# 007　内核：你的三个「自我」

- **解决的问题**：后悔一时冲动、感到能力不足、羡慕更高境界时，你都在问「我怎么才能变得更好」——光有成长思维模式不够。
- **核心概念**：
  - **进程自我**：你时刻直观感觉到的那个「我」，是大脑维持「这里有个主体」的在线计算（佛学五蕴可看作它的细分模块）。
  - **界面自我**：叙事中更稳定、可控、可被别人认可的角色，即性格标签与人设，是变量而非常量。
  - **内核自我**：背后生成前两者的那套庞大、复杂的概率分布与先验，是出厂设置加历史数据的总和，藏着所有直觉与潜意识判断。
  - **AI 类比**：进程自我 = 当前推理过程；界面自我 = 系统提示词与角色设定；内核自我 = 模型结构与权重。
  - **两个调参杠杆**：预训练语料（你从小到大看听的故事、模仿的行为、加入的群体）与强化学习的奖励函数。
- **关键洞察**：
  - 进程自我是被动的：实验显示人在「意识到」决定前大脑已做了决定，它只是新闻发言人，查看日志碰不到决定命运的东西。
  - 界面自我有因果力（内向者也能要求自己今天扮演社牛），但那只是激活不是能力提升，遇高压就崩。
  - 面对现实打脸，三个选择：改注意力（别看）→ 改行为（绕开）→ 改模型（承认我错了）；改模型最难但最值钱。
  - 人比 AI 高一层：你可以自己选择训练样本和奖励函数，这是人的终极自由，也是最根本的元认知——「是谁在训练我？」
- **权威来源**：丹尼特「叙事重心」；弗里斯顿「自由能原理」；克拉克《Surfing Uncertainty》(2016)；佛学五蕴、阿赖耶识；「吾日三省吾身」。
- **怎么用**：① 别把优化界面当成升级内核，抓住被现实顶回来的时刻承认旧模型还在；② 管好输入信息与奖励函数，并小心选择伴侣、朋友圈和公司文化；③ 反复自问「是谁在训练我、我为什么要往那个方向变」。
