# 023　问答：如何判断“该深耕”还是“该挪位置”？

（答疑：《社交资本、结构洞和搬家》《认知解耦》《身份认同》《安全感》《赛道选择》诸讲）
- **解决的问题**：现在的不顺是暂时的还是位置本身没前途？认知重评会不会沦为自我安慰？责任与自我如何两全？
- **核心概念**：判断位置的三个信号：参考类（背景相近的人都怎么样了、上去的人凭能力还是凭关系）、宏观市场前景、个人体感是否在积累复利。
- **关键洞察**：真认知重评与阿 Q 精神的区别是事实，与辩证法的区别是具体。信任不是个人品质而是互动，无法用指标描写，必须现场相处才能建立。好妈妈不等于在场总时长，而是在场质量；研究说的是让孩子感到被忽略才不利。依赖要分清：被依赖是你的存在对他人重要，背负他人人生是对方把人生外包给你。赛道不止两种，还有太上老君、工匠、散仙、小妖。
- **权威来源**：默会知识（后讲）；丘成桐「在新疆也能研究数学」；先验 priors 概念（后讲决策时展开）。
- **怎么用**：用三个信号给自己定位，别把结构问题当成个人失败；用「事实」和「具体」两把尺子校准重评，避免自我欺骗；做依赖关系时给人赋能不让人失能，并想清楚自己的定位（比如当工匠就别参与政治）。
