# 术语表（万维钢·现代思维工具100讲）

| 术语 | 英文原名 | 一句话定义 | 讲次 |
|---|---|---|---|
| Ruliad | Ruliad | 沃尔夫勒姆说的「一切可能计算的纠缠极限」，即所有可能物理定律的总集合，我们的宇宙只是其中一个小切片。 | 001 |
| 叙事重心 | center of narrative gravity | 丹尼特语：自我不是实体，只是叙事产生的一个重心——不是因为「我」才有叙事，而是因为叙事才有「我」。 | 001 |
| 重尾分布 | heavy-tailed distribution | 极端少数占特别大份额的分布，最典型是幂律；对重尾谈平均值没有意义，社会变量多是重尾。 | 002 |
| 吉布拉特定律 | Gibrat's law | 公司增长率与规模近似无关，所以体量差距必然越拉越大，是重尾世界的成因之一。 | 002 |
| 乘法世界与加法世界 |  | 乘法世界的增量＝当前动作×存量，有复利；加法世界是一天劳动换一天报酬，两者补短板与做长板的规则不同。 | 002 |
| 文化滞后 | cultural lag | 观念更新总比物质条件改变慢很多，于是匮乏时代形成的生存逻辑会长期残留为价值观、道德乃至审美。 | 003 |
| 内核自我 |  | 生成进程自我与界面自我的那套庞大先验与概率分布，即出厂设置加历史数据的总和，藏着直觉与潜意识判断。 | 007 |
| 能耐寻求定理 | power-seeking theorem | 特纳 2021：奖励位置不确定时最优策略是最大化「能耐」，即对环境的选项与影响力；有两条路就走通向更多地点的那条。 | 008 |
| 供给侧心态 |  | 不问我能得到什么，只问我能提供什么；把自己当提供可验证价值的模块，主动降低协作摩擦，嵌入长期重复博弈。 | 009 |
| 逆火效应 | backfire effect | 指出错误反而让对方更坚定；根因是观念与身份认同、社会归属绑在一起，质疑观念等于质疑他的存在合理性。 | 011 |
| 自我决定理论 | self-determination theory | 德西与瑞安：动机质量比强度重要，动机是从无动机到内在动机的六层连续体，控制点由外向内移。 | 012 |
| 自由能原理 | free energy principle | 弗里斯顿：生命通过马尔可夫毯与环境耦合，持续最小化自由能（≈惊讶），办法是知觉推断与主动推断。 | 013 |
| 马尔可夫毯 | Markov blanket | 把系统与环境分开的统计边界，系统只能通过毯上的状态感知外界并影响外界，是自由能原理的耦合界面。 | 013 |
| 主动高认知负荷 |  | 借斯韦勒认知负荷理论，由你单方面给任何任务加载约束和问题，把注意力手动切到建构图式的 Pro 模式。 | 014 |
| WOOP | WOOP | 厄廷根四步：写下愿望、结果与内心障碍，再用 If-Then 写好应对动作，把愿望接上自动触发的执行程序。 | 015 |
| 结构洞 | structural holes | 伯特：两个互不相连的网络之间的空缺；站在洞上做经纪人，就能同时掌握两边信息并赚取中介收益。 | 016 |
| 吸血鬼悖论 |  | 没成为吸血鬼就不知道做吸血鬼的感受；感受和判断只能在行动之后出现，所以要先做起来再一边内化。 | 017 |
| 认知解耦 | cognitive decoupling | 把「心中的叙事」和「眼前的事实」拆开，经认知解离、调用视角、认知重评三步调节负面情绪。 | 018 |
| 主体—客体转化 | subject-object transformation | 凯根：把「我就是这个身份」变成「我在调用这个身份」，身份从支配你的主体变成你可操作的客体。 | 019 |
| 赛道选择 | Game Selection | 先选玩什么游戏再谈最优策略；体制内是适应别人建立的秩序，体制外是直面真实世界并自负风险。 | 021 |
| 场域 | field | 布迪厄：由不同位置构成的关系网络，有自己的规则、筹码和裁判；同一个人在不同场域的价值完全不同。 | 022 |
| Doxa | Doxa | 场域里不言自明、无须论证的信念，它不被讨论，却决定了什么算问题、什么算答案。 | 022 |
| 探索与利用 | explore-exploit tradeoff | 源自多臂老虎机：探索是花成本换信息，利用是对已知信息榨取最大收益；原则是先探索再利用，且不能只探索不利用。 | 024 |
| 多臂老虎机 | multi-armed bandit | 探索与利用权衡的原型问题：面对多台收益未知的老虎机，每拉一次都要在试新和守旧之间取舍。 | 024 |
| 共鸣 | resonance | 罗萨：独立主体之间的相互回应与共振，而非把世界当资源；分横向（人）、斜向（物与工作）、纵向（宏大存在）。 | 025 |
| 无免费午餐定理 | No Free Lunch Theorem (NFL) | 沃尔珀特与麦克雷迪 1997 年证明：把所有问题平均来看任何两个算法表现相同，所以决策必须先有归纳偏置。 | 026、120 |
| 归纳偏置 | inductive bias | 你不问理由地相信点什么，才能从有限经验中学习；先验用来圈定搜索空间与目标函数，是决策的第一步。 | 026 |
| 结果偏误 | outcome bias | 只看结果好坏评价决策，而不看决策时的概率分布；赢一次不等于决策对，长期胜率才是标准。 | 027 |
| 好调节器定理 | good regulator theorem | 科南特与阿什比 1970：系统的每一个好调节器都必须是该系统的一个模型，没有模型就无法有效调节。 | 028 |
| 循吏 |  | 出自《史记》：遵法理与常情、不站队不折腾的官员；乱世里不做酷吏也不当隐士，靠秩序输出者的身份生存。 | 029 |
| 贝叶斯先验 | prior | 概率是对你无知程度的度量；先验是可量化、可更新、可审计的认知起点，后验＝先验×证据修正。 | 030 |
| 信息价值 | value of information (VOI) | 只有能改变实际行动的信息才有价值；VOI＝有这条信息时的最佳选择比没它时平均多赚多少。 | 031 |
| 凯利公式 | Kelly criterion | 乘法式重复下注中使长期复合增长率最大的下注比例 f*≈edge/odds；增长上限受限于你的认知带宽。 | 032 |
| 非遍历性 | non-ergodicity | 集合平均不等于个体时间平均：赢增 50%、输减 40% 的单次期望为正，但 1.5×0.6＝0.9，长期必然破产。 | 033 |
| 杠铃策略 | barbell strategy | 把绝大部分资源放在极安全处，只用小部分押极高赔率，避开中间地带，使波动只带来好处不带来毁灭。 | 033 |
| 反脆弱 | antifragile | 收益函数为凸：损失极有限、收益无上限，于是波动和压力反而让它变强，与凹性的脆弱正好相反。 | 034 |
| 毒物兴奋效应 | hormesis | 小剂量压力或毒素反而激发系统变强；主动注入小不确定性，是把波动变成营养的反脆弱做法。 | 034 |
| 期权 | real option | 只是权利不是义务；未来有多条路径且你对某个结果拥有专有进入权时，可先小额买入选择权而不必现在锁定。 | 036 |
| 状态杠杆 |  | 这一步做完之后世界会不会对下一步更友好；要优化的不只是动作，更是动作之后留下的状态。 | 037 |
| 伯克森悖论 | Berkson's paradox | 只看跨过某个门槛（如住院、入选）的样本，会伪造出原本不存在的负相关，是门槛偏差的典型形式。 | 038 |
| 回归均值 | regression to the mean | 高尔顿 1886：观测结果＝真实水平＋随机运气，极端表现常伴随极端运气，下次运气大概率不重现。 | 039 |
| 前景理论 | prospect theory | 卡尼曼与特沃斯基 1979：人看的是相对参照点是赚还是亏，而不是绝对财富，所以损失区比收益区陡得多。 | 040 |
| 设计结构矩阵 | Design Structure Matrix (DSM) | 把步骤同时列在横纵坐标、有依赖就打点：点靠近对角线说明排序好，边缘有点说明顺序错，回环说明这是迭代流程。 | 041、037 |
| 参考类预测 | reference class forecasting (RCF) | 从内部视角切到外部视角，找一组数量足够多、足够相似且已结束的案例，用其平均成本和失败率当基准线。 | 042 |
| 费米化 | Fermi estimation | 把边界模糊的云状问题拆成可判定的具体小问题再逐步估算，是概率化预测的第一步。 | 043 |
| OODA 环 | OODA loop | 观察—定向—决策—行动；精髓不是反应快而是换脑快，第二个 O「定向」是整个循环的阵眼。 | 044 |
| ICAP 框架 | ICAP framework | 季清华按外显行为分被动、主动、建构、互动四级，学习效果严格是 I>C>A>P。 | 046 |
| 综合调研 | Synthesis | 自己立题、自己找材料、自己判断可信度，回答「所以呢」并写成报告；分定位式、结构化、生成式三级。 | 050 |
| 默会知识 | tacit knowledge | 波兰尼：只可意会不可言传的知识，与显性知识相对，即赖尔说的「知道怎么做」而非「知道是什么」。 | 051、054 |
| 可取困难 | desirable difficulties | 比约克夫妇：某些阻力会让短期表现变差、长期记忆与迁移却更强；前提是分清「表现」与「学习」。 | 052 |
| 信号筛选 | signaling | 教育的一种功能不是教本事而是排序，用考试把人分层，向雇主发出能力信号。 | 054 |
| 拥抱与桥接 | hugging and bridging | 珀金斯与所罗门：拥抱是让教学贴近未来应用情境（低路迁移），桥接是抽取图式再类比到别处（高路迁移）。 | 056 |
| 经济租 | economic rent | 一笔收入里超过「让该资源继续被提供所需最低报酬」的部分；收益＝创造的价值×捕获系数。 | 057 |
| Alpha | Alpha | 扣除市场共同风险（Beta）之后，靠更高一层认知与动作多拿的超额收益；凝固成品牌与专利后成为经济租。 | 058 |
| MM 定理 | Modigliani-Miller theorem | 莫迪利亚尼—米勒：债务不创造财富，只是重新分配风险和收益——这就是所谓 MM 定理。 | 060 |
| 机会窗口 | window of opportunity | 苏亚雷斯：入场窗口从「主导类别」出现时打开，到「主导设计」出现时关闭；来早了替后人开荒，来晚了只能喝汤。 | 061 |
| 效果推理 | effectuation | 萨拉斯瓦蒂：手段已知、创造目标——先用手里已有的东西干出一个会改变下一步的小结果，与因果推理相对。 | 062 |
| 沃德利地图 | Wardley map | 纵轴是价值链可见度、横轴是演进四阶段（创生→定制→产品→商品），万物都在向右移动，据此决定自做还是外包。 | 063 |
| 鲍莫尔成本病 | Baumol's cost disease | 停滞部门生产率难提高却必须跟着进步部门涨工资，于是艺术、医疗、教育的相对成本不可遏制地上升。 | 064 |
| 杰文斯悖论 | Jevons paradox | 效率提高反而增加总消耗；把「提高效率」换成「自动化」、「资源」换成「人的工作」，就得到自动化会增加人的工作。 | 066 |
| 衰败化 | Enshittification | 平台堕落三阶段：先补贴讨好用户，再牺牲用户讨好商家，最后牺牲商家把价值收回自己。 | 067 |
| 可托付性 | Entrustability | 把一团混沌压缩成可判断、可执行、可负责的局面；公司用高薪买的正是这种能力，它比技能更稀缺。 | 068、071 |
| 支配与声望 | dominance and prestige | 争地位的两条路：支配靠权力资源让人恐惧，声望靠能力与慷慨让人自愿追随。 | 069 |
| 礼 |  | 本质是社会互动协议，把抽象价值翻译成具体动作；不靠警察执行，处在市场与法律之间的中间地带。 | 070 |
| 激励相容 | Incentive Compatibility | 让普通人在追求自身利益的同时顺手完成制度想要的事；机制设计就是给定结果反推规则的逆问题。 | 072 |
| 柠檬市场 | market for lemons | 阿克洛夫：信息不对称下买家只肯出平均价，好货退出、坏货留下，价格再降，形成死亡螺旋直到良币消失。 | 073 |
| 公共品 | public goods | 同时具备非排他性与非竞争性的东西：谁都挡不住别人用、多一个人用也不减少别人的份额。 | 074 |
| 科斯定理 | Coase theorem | 产权清晰、交易成本为零时，无论产权归谁都能通过谈判达到有效结果；真正的遗产是先算交易成本再选制度。 | 074 |
| 黄宗羲定律 |  | 轻徭薄赋→官僚扩张→加税→并税改革→再发明杂税，税制越改越重的「积累莫返之害」。 | 075 |
| 软预算约束 | soft budget constraint | 科尔奈：外部力量替你填窟窿的主观概率越高，你的预算约束就越软，责任与效率随之变形。 | 076 |
| 可读性 | legibility | 斯科特：国家为了让社会能被统计、征税、征兵，要求社会按自己方便的方式排列，代价是抹掉地方性智慧。 | 078 |
| 米提斯 | mētis | 在永远变化、从不重复的现场里临机应变、把事情做成的活智慧，与可书写可统计的显性知识相对。 | 078 |
| 共同知识 | common knowledge | 我知道你知道我知道……层层嵌套无穷的知识，是一间互相反射的镜厅，也是让一片人同时行动的总开关。 | 079、088 |
| 瑞士奶酪模型 | Swiss cheese model | 瑞森：重大事故很少是单一原因，而是多道防线的洞恰好排成一条直线；最该整改的是潜在条件而非一线的人。 | 080 |
| 非预期后果 | unintended consequences | 默顿：人们响应的是激励而不是意图；你改变不了结果本身，只能改变局面，人们会在新局面里重新优化行为。 | 081 |
| 切斯特顿的篱笆 | Chesterton's fence | 看到一道不知用途的篱笆先别拆；不理解一个制度为何存在就改动它，往往会让它原先挡住的坏事重新发生。 | 081 |
| 慢变量 | slow variables | 霍林：复杂系统里变化慢、不显眼却决定韧性的变量（产权、法治、信用），与看得见易考核的快变量相对。 | 082 |
| 稳定预期 |  | 政府能给社会最贵的礼物：让农民敢种地、企业敢投资、家庭敢买房、年轻人敢学长期技能，努力不被轻易作废。 | 082 |
| 摩洛克 | Moloch | 「多极陷阱」：多人竞争，每个人做对自己最理性的选择，加在一起却把所有人推向谁都不想要的结局。 | 083 |
| 第三物 | third object | 能被双方共同看见、共同操作的东西，把「人对人」的直接僵局改造成「人围物」的共同局面。 | 084 |
| 剩余判断权 | residual rights of control | 合约写不尽的剩余事项上，由一人设定主观战略、确保执行并担责，这是组织总得有人说了算的原因。 | 085 |
| 组织资本 | organizational capital | 长在人与人之间、靠长期协作攒下的专用能力：谁知谁擅长什么、谁跟谁搭配最顺，含认知、结构、关系三维。 | 086、088 |
| 叙事权 |  | 用定题（议程设置）、定义（框架塑造）、定我（身份认同）三个心法，把私人信念变成组织的共同知识。 | 087 |
| 人身依附 |  | 前现代管理的灵魂：靠恩、威、亲、表把人绑在具体的人身上，规矩长在人身上而不是长在角色上。 | 089 |
| 邓巴数 | Dunbar's number | 人脑能稳定维持的熟人关系约一百五十人；超过之后就需要中层做信息关口，组织形态随之改变。 | 089 |
| 古德哈特定律 | Goodhart's law | 指标本来用来观察现实，一旦变成奖惩目标，人们就转而优化指标而不再优化现实。 | 093、118 |
| 智件 |  | 长在组织身上的聪明：沉淀方法（技能）、标准（护栏）和经验（记忆）；制度保证组织不乱，智件保证组织不笨。 | 094 |
| 基线漂移 | shifting baseline syndrome | 要害不是世界变差，而是评价世界的尺子也跟着一起变差，于是不正常慢慢变得正常。 | 095 |
| 生成 | generativity | 让一个东西因你而生、却不靠你而活、不照你而变；两门功夫是组织闭合与可演化性。 | 097 |
| 组织闭合 | organizational closure | 系统赖以存活的每个关键环节都能在系统内找到供养它的另一个环节，所以你离开后它仍能运转。 | 097 |
| 对称性破缺 | symmetry breaking | 从「什么都可能」变成「只有一种可能且坚不可摧」；早期宇宙只有十万分之一的密度涨落，却冷却成了星系的位置。 | 098 |
| 临近可能 | adjacent possible | 系统周围那一圈只差一步就能实现的新状态；行动要满足临近、留下现实构件、能参与下一次组合三个条件。 | 099 |
| 反馈回路 | feedback loop | 因果绕一圈回来（A→B→C→A）：正反馈放大变化，负反馈纠正偏差；复杂系统真正起决定作用的回路通常只有几条。 | 104 |
| 自组织临界 | self-organized criticality | 系统自带平衡回路，能把亚临界与超临界自动拉回临界（分支比≈1）；表现为信息传得远、特别敏感但恢复慢。 | 105 |
| 边际分析 | marginal analysis | 看下一个单位投入带来多少新增产出；边际效益＝边际收益−边际成本，四象限决定加大、维持还是退出。 | 106 |
