# 实践模式与反模式

## 目录

## 概览

本文件汇集了古典智慧在不同场景下的实践模式（正确做法）和反模式（常见错误），帮助用户将经典智慧落地为可操作的行动指南。

## 决策场景

### 模式：知彼知己的系统决策

**正确做法**：
1. 全面收集信息，了解外部环境（彼）
2. 客观评估自身优劣势（己）
3. 列出成功必要条件
4. 评估每个条件的达成概率
5. 预设风险和应对方案

**反模式**：
- 凭直觉冲动决策
- 只看有利因素，忽视风险
- 信息收集片面，偏听偏信
- 过度分析，迟迟不行动

### 模式：庙算评估法

**正确做法**：
1. 明确决策目标
2. 分析道、天、地、将、法五个维度
3. 进行七计对比
4. 综合评估胜算
5. 设定决策时限

**反模式**：
- 不做评估就行动
- 只看短期，不看长期
- 被情绪主导决策
- 盲目从众

### 模式：两难抉择的中道法

**正确做法**：
1. 识别矛盾的本质
2. 分析每个选项的短期和长期影响
3. 寻找超越二元对立的第三选择
4. 选择让自己心安的那个选项

**反模式**：
- 非此即彼的思维
- 只看眼前利益
- 选择后反复后悔
- 被他人意见左右

## 修养场景

### 模式：每日三省的习惯

**正确做法**：
1. 每天固定时间反思
2. 从三个维度检视：忠（职责）、信（承诺）、习（成长）
3. 记录反思日志
4. 针对问题制定改进措施

**反模式**：
- 从不反思
- 反思流于形式
- 只找借口，不找方法
- 三分钟热度

### 模式：事上磨练的修行

**正确做法**：
1. 把每一件事当作修炼的机会
2. 遇到挑战时保持警觉
3. 在逆境中锻炼心性
4. 事后复盘总结

**反模式**：
- 逃避困难
- 找借口推脱
- 遇到问题就抱怨
- 消极应对

### 模式：诚意正心的自检

**正确做法**：
1. 做事前先问动机
2. 检视是否有私心杂念
3. 问自己是否愿意公开动机
4. 确保言行一致

**反模式**：
- 自欺欺人
- 言行不一
- 动机不纯
- 表面一套背后一套

### 模式：破心中贼的修炼

**正确做法**：
1. 觉察心中的贼（怠心、忽心、躁心、妒心、贪心等）
2. 保持警觉，不让杂念主导
3. 用正念纠正
4. 持续修炼

**反模式**：
- 不自知
- 放任自流
- 事后后悔
- 反复犯同样的错

## 管理场景

2. 换位思考

4. 以身作则

**反模式**：
- 双重标准
- 只管别人不管自己
- 以权压人
- 任人唯亲

### 模式：修齐治平的次第

**正确做法**：
1. 从修身开始
2. 修身有成则齐家
3. 家齐则治企
4. 企治则服务社会

**反模式**：
- 想走捷径
- 忽视基础
- 管理混乱
- 急于扩张

### 模式：得人心的管理

**正确做法**：
1. 以人为本
2. 关注下属成长
3. 公正透明
4. 愿景引领

**反模式**：
- 只看业绩
- 忽视员工感受
- 暗箱操作
- 命令式管理

**反模式**：
- 知而不行
- 行而不知
- 纸上谈兵
- 行动迟缓

**反模式**：
- 说得多做得少
- 只说不做
- 光说不练
- 夸夸其谈

- 错失良机

## 道德场景

### 模式：义利之辨的选择

**正确做法**：
1. 先问是非
2. 再论得失
3. 不义之利不取
4. 短期利益服从长期价值

**反模式**：
- 见利忘义
- 唯利是图
- 不择手段
- 利益熏心

### 模式：浩然之气的培养

**正确做法**：
1. 长期做正当的事
2. 保持正直诚信
3. 面对压力不屈服
4. 积累正能量

**反模式**：
- 投机取巧
- 见风使舵
- 屈服压力
- 丧失气节

### 模式：致良知的判断

**正确做法**：
1. 问自己是否心安
2. 是否对得起良心
3. 是否能坦荡面对
4. 做出正确选择

**反模式**：
- 昧着良心
- 自欺欺人
- 随波逐流
- 丧失底线

## 复盘场景

### 模式：日日复盘的习惯

**正确做法**：
1. 每天固定时间复盘
2. 检视目标达成情况
3. 分析得失
4. 制定改进措施

**反模式**：
- 从不复盘
- 复盘走过场
- 只看失败不看进步
- 复盘后不改进

### 模式：从经验中提炼原则

**正确做法**：
1. 从多次经验中归纳
2. 形成可复用的原则
3. 用原则指导行动
4. 持续迭代升级

**反模式**：
- 经验主义
- 不总结归纳
- 同样的错误反复犯
- 不会举一反三
