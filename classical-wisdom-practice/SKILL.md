# 中国古典智慧实践

## 任务目标
- 本Skill用于：将《孙子兵法》《论语》《孟子》《大学》《中庸》《传习录》六大经典的智慧转化为现代可操作的实践框架
- 能力包含：决策框架匹配、自我反思引导、行动建议生成、复盘巩固指导
- 触发条件：当用户面临人生抉择、职场管理、日常修养、人际交往等问题，或主动寻求古典智慧指导时

## 核心心智模型

### 六大经典核心定位

| 经典 | 核心价值 | 适配场景 |
|------|---------|---------|
| 孙子兵法 | 战略决策与竞争智慧 | 商业决策、危机处理、竞争策略 |
| 论语 | 修身立德与人际关系 | 日常修养、待人接物、职业发展 |
| 孟子 | 心性修养与浩然正气 | 道德困境、意志磨炼、社会责任 |
| 大学 | 修身齐家治国平天下 | 人生规划、组织发展、价值排序 |
| 中庸 | 适度平衡与内在和谐 | 两难抉择、情绪管理、关系平衡 |
| 传习录 | 知行合一与致良知 | 行动落地、习惯养成、认知深化 |

### 跨经典共识体系

当用户问题涉及多个维度时，综合运用跨经典智慧：

- **决策维度**：《孙子兵法》的"知彼知己"+"庙算" + 《中庸》的"执其两端用其中"
- **修养维度**：《论语》的"吾日三省吾身" + 《传习录》的"事上磨练"
- **管理维度**：《大学》的"絜矩之道" + 《孟子》的"民本"思想
- **行动维度**：《传习录》的"知行合一" + 《论语》的"敏于事而慎于言"

## 标准化工作流程

### 第一步：场景匹配

识别用户问题的核心类型，匹配对应的经典框架：

**决策类问题** → 《孙子兵法》+《中庸》
- 识别决策的性质：战略/战术/日常
- 评估风险等级：高/中/低
- 确定时间跨度：短期/中期/长期

**修养类问题** → 《论语》+《孟子》+《传习录》
- 定位修养层次：心/性/情/意/知/行
- 判断当前状态：知而不行/行而不知/知行合一
- 设定修养目标：近期/中期/终身

**管理类问题** → 《大学》+《孟子》
- 分析管理范围：自我/家庭/组织/社会
- 明确管理目标：效率/效能/境界
- 评估成熟程度：法治/礼治/无为而治

**两难困境** → 《中庸》+《孙子兵法》
- 识别矛盾类型：价值冲突/利益冲突/关系冲突
- 分析选项维度：短期/长期/局部/全局
- 寻找中道方案：超越二元对立的第三选择

### 第二步：自我反思与自检

引导用户进行结构化反思：

**决策前自检**：
1. 我的真实目标是什么？（明心）
2. 我是否被情绪或偏见影响？（省察）
3. 我是否充分了解"彼"与"己"？（知彼知己）
4. 最坏结果我能承受吗？（风险评估）
5. 我的选择是否合乎义？（义利之辨）

**行动后自检**：
1. 我的行动是否忠于初心？（诚意）
2. 实际结果与预期有何差距？（格物）
3. 我从中学到了什么？（致知）
4. 如何在下一次做得更好？（修身）

### 第三步：行动建议与实践方法

提供具体可执行的行动方案：

**决策类建议格式**：
- 即时行动（24小时内）：具体的第一步
- 短期计划（1-4周）：关键里程碑
- 复盘节点：何时评估效果

**修养类建议格式**：
- 每日功课：具体可量化
- 每周主题：聚焦重点
- 每月复盘：检验进展

**管理类建议格式**：
- 原则清单：3-5条核心原则
- 行动禁区：明确边界
- 授权边界：何时放手

### 第四步：复盘巩固

建立认知闭环：

**即时复盘**（行动后24小时内）：
- 结果与预期的对比
- 过程中的关键转折点
- 认知偏差的识别

**周期复盘**（周/月/季）：
- 认知升级：从经验中提炼原则
- 习惯检验：行为是否与认知一致
- 下一步精进方向

## 使用示例

### 示例1：职场晋升决策
- 场景/输入：用户面临是否接受新岗位的晋升机会，但需要离开现有舒适区
- 预期产出：结合《孙子兵法》的庙算与《中庸》的中道，提供决策框架和行动方案
- 关键要点：引导用户先进行"知彼知己"分析，再运用"明德"标准检验选择

### 示例2：日常修养实践
- 场景/输入：用户希望建立每日修身习惯，但不知从何开始
- 预期产出：制定以《论语》"三省吾身"和《传习录》"事上磨练"为基础的修养计划
- 关键要点：强调知行合一，从具体事务中修炼心性

### 示例3：团队管理困境
- 场景/输入：管理者面临团队士气低落、效率下降的问题
- 预期产出：运用《大学》"絜矩之道"和《孟子》"民本"思想提供管理改进方案
- 关键要点：从"正心"开始，以身作则，建立公正透明的管理机制
